## この記事について
Code Review がリサーチプレビューを終え、Claude Team および Enterprise の組織で一般提供（GA）になった
ことの告知です。プレビューからの変更点は 3 つ——レビューの速さ、より的を射た指摘、そして管理者が
リポジトリ単位で選べるレビューの深さです。

## どんなときに役立つか
- Team または Enterprise の組織で、Code Review を有効にするか、どのリポジトリに適用するかを判断するとき
- プレビュー時のレビューが日常的な変更には遅すぎる・うるさすぎると感じ、全体に同じ設定を当てるのでは
  なくリポジトリごとに深さを調整したいとき
- エージェントを使った開発でプルリクエストの量が、人のレビュー能力より速く増えてしまったとき

## 主なポイント
- Code Review はリサーチプレビューを終了し、Claude Team・Enterprise プランで一般提供されます。
- 対象となる Claude Enterprise 組織は、2027 年 1 月 15 日までに 10,000 ドル以上の Code Review
  クレジットを申請できます。クレジットは申請から 30 日で失効し、規約が適用されます。
- 速度: ほとんどのレビューがプレビュー時より約 3 倍速く完了します（約 20 分 → 6〜10 分）。
- 品質: 重要なバグをより多く見つけ、問題・何がそれを引き起こすか・修正方法を数文で明確かつ簡潔に示します。
- 柔軟性: 管理者がリポジトリごとに Quick、Standard（既定）、Deep を選べます。日常的なコードベースは
  素早いパスで、最も重要なものは深いレビューで扱えます。どの水準でも高品質なレビューが提供されます。
- Anthropic 自身も自社のプルリクエストに Code Review を走らせており、レビューが自社エンジニアの速度を
  どこで落としているかを把握しています。
- 管理者の設定: Claude Code の設定で Code Review を有効にし、GitHub App をインストールし、レビュー対象の
  リポジトリを選びます。開発者側の設定は不要で、新しい PR で自動的にレビューが走ります。

## 同梱リソース
- Skill: `code-review-rollout` — 組織で Code Review を有効にし、リポジトリごとにレビューの深さを割り当てる
  手順。3 つの深さの水準とクレジットプログラムのリファレンスを同梱。
