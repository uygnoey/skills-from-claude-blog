## What is this post?
Anthropic announces that Claude for Government — Claude's coding and agentic work capabilities in a
FedRAMP High authorized environment, in public beta since July — is generally available to federal
and state agencies. The Claude Code CLI and Claude for Microsoft 365 are rolling out in early access
in the same environment.

## When is it useful?
- When an agency is evaluating or onboarding Claude for Government.
- When administrators plan spend caps, seat tiers, and sub-agency administration.
- When security teams or authorizing officials gather evidence for an ATO or IG request.
- When procurement officers want to contract directly on general-availability terms.

## Key points
- Capabilities comparable to commercial customers; new capabilities generally arrive on the
  commercial release cadence. Staff use skills, plugins, and projects on desktop files for memos,
  RFP reviews, and casework; Claude Code helps build and modernize public-service software.
- No seat fees: usage in fixed increments with a hard not-to-exceed cap, per-group spend and model
  limits, usage tracking by user and model, and burndown alerts.
- Department admins allocate prepaid usage to sub-agencies, each managing its own users. Own IdP for
  SSO (self-serve), SCIM group mappings for rate limits, dollar caps, and allowed models, and layered
  configuration defaults for connections and features.
- Oversight: admin audit log, two-person approval for sensitive operations on Anthropic's side,
  metering-only usage exports, and conversation history kept on the agency-managed device.
- No separate cloud-provider relationship needed; MDM deployment; in-app history import; FedRAMP
  Secure Configuration Guide in Anthropic's trust center.
