# In-app survey plan

Help Center: "Create surveys for your organization"
(https://support.claude.com/en/articles/16764057-create-surveys-for-your-organization).

## Default questions (focused on value)
The post lists four default themes. Wording below is a paraphrase; keep, edit, or remove each one.

1. What is the most valuable thing you have done with Claude recently?
2. How did Claude change the time that work took?
3. Which use of Claude should a teammate copy?
4. If the team lost access tomorrow, what would break or slow down first?

## Data handling
- Can be enabled for organizations using customer-managed encryption keys.
- With one organization-wide retention period, surveys and responses are deleted on that schedule.
- Survey data is treated as the customer's data; Anthropic accesses it only as needed to operate the service.
