## 이 글이 뭔가요
Anthropic이 Claude Startups 프로그램을 확대해 창업자가 처음부터 Anthropic의 모델·도구·사람에 접근할
수 있게 한다는 발표입니다. 2026-10-13 업데이트에 따르면 이번 기수는 마감되어 신규 신청을 받지 않습니다.
현재 상태는 프로그램 페이지에서 확인하세요.

## 언제 유용한가요
- 창업자가 Claude 스타트업 크레딧 대상인지 알고 싶을 때.
- Team 좌석, API 크레딧, 파트너 할인을 어떻게 쓸지 계획할 때.

## 핵심 포인트
- 자격: 설립 5년 이내이거나 최근 2년 안에 투자를 받은 스타트업.
- 최대 $7,000 상당의 Claude 크레딧: Claude Team 1년 무료(Premium 좌석 최대 5개, Team을 처음 쓰는
  회사 대상)와 승인 시 1회성 $1,000 API 크레딧.
- Claude Startup Stack: 영업·디자인·데이터 엔지니어링 등 파트너 도구에 대한 최대 $45,000 상당의 할인과
  크레딧.
- 그 밖에: Applied AI 팀과의 온라인 오피스 아워, Claude Marketplace 등록 지원, 이벤트(Founder House,
  해커톤, 밋업)와 Startup Newsletter.
- 유의점: $7,000은 Premium 좌석 5개 × 좌석당 월 $100(연간 청구) 기준이고, 크레딧은 Supplemental Credit
  Terms를 따르며, Stack 가치는 2026년 9월 정가 기준입니다.
- 신청: claude.com/programs/startups.
