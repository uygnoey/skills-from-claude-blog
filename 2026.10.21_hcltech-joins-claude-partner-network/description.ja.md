## この記事について
60 か国で 23 万人以上が働く HCLTech が Claude Partner Network に Global Premier パートナーとして参加し、
銀行・病院・通信会社・製造業に、リスクの高い環境に合った統制とともに Claude を届けるという発表です。

## どんなときに役立つか
- システムインテグレーターや ISV が自社の Claude 事業を設計するとき。
- 規制業種の顧客から、本番投入前に Claude をどう検証し監督するのかを問われたとき。

## 主なポイント
- 第 1 の柱: Anthropic 専任の事業部門と Center of Excellence。顧客先に入るエンジニアが、顧客自身の
  システムとデータで Claude を試せる安全なサンドボックスを作り、顧客の人材を育成し、エージェントを
  大規模に安全運用するための統制を整えます。
- 第 2 の柱: HCLSoftware が Anthropic の ISV パートナーとなり、HCL BigFix（エンドポイント管理）、
  HCL AppScan（アプリケーションセキュリティテスト）、Actian AI analyst（データ・分析）から Claude を
  組み込みます。
- 第 3 の柱: AI Force（IT サポート、コード修正、デジタル従業員サービス）に Claude と Claude Code を
  載せ、ポリシーのガードレール、例外処理、人による監督を置きます。顧客の本番システムに影響する作業は
  エンジニアがレビューし承認します。
- C Vijayakumar 氏（HCLTech）と Daniela Amodei 氏（Anthropic）が規模、製品の深さ、信頼について語って
  います。
