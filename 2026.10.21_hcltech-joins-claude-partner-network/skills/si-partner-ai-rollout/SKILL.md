## Purpose
HCLTech (230,000+ people, 60 countries) will bring Claude to banks, hospitals, telecom companies, and
manufacturers along three tracks. This skill turns that structure into a checklist for any
integrator or enterprise IT group planning a similar Claude practice. Details of HCLTech's own plan
are in [references/hcltech-three-tracks.md](references/hcltech-three-tracks.md).

## When to use
- A systems integrator or consultancy is designing its Claude practice.
- A software vendor wants to embed Claude in existing products.
- A managed-services team wants agents to handle routine IT work under human oversight.
- A regulated client asks how Claude will be tested and controlled before production.

## Instructions

1. **Pick the tracks that apply.** Map the organization to one or more of:
   - **Practice / CoE** — client-facing engineering and enablement.
   - **Product (ISV)** — Claude inside the firm's own software.
   - **Platform / managed services** — Claude and Claude Code running operational work.

2. **Practice / CoE track.**
   - Assign forward-deployed engineers to client engagements.
   - Build a secure sandbox per client so Claude is tested on the client's own systems and data
     before any rollout.
   - Plan workforce training for the client's staff.
   - Define the controls needed to run agents safely at scale.

3. **Product (ISV) track.**
   - List products where Claude adds value; HCLSoftware's first picks span endpoint management,
     application security testing, and data and analytics.
   - Start with a small number of flagship products, then expand across the portfolio.

4. **Platform / managed-services track.**
   - Put policy guardrails, exception handling, and human oversight in the platform.
   - Let agents handle routine work (e.g. IT support, code remediation, digital employee services).
   - Require engineer review and approval for anything that affects a client's production systems.

5. **Write the trust case.** For each track, state how the client can verify the controls. The
   announcement frames it simply: AI is only as useful as it is trustworthy.

6. **Do not invent program terms.** Partner tiers, commercial terms, and eligibility are not in the
   announcement; point to the Claude Partner Network page.

## Examples
- A mid-size integrator serving hospitals: start with the CoE track — sandbox on a de-identified copy
  of the client's systems, train clinical IT staff, define agent controls — before any production
  agent.
- A security-software vendor: follow the ISV track, embedding Claude first in its application
  security testing product (as HCL AppScan is doing).
- An IT outsourcing team: run Claude Code for code remediation in its service platform, with
  engineers approving every change that reaches client production.
