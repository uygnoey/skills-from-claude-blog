## What is this post?
The September 16, 2026 announcement that Claude Cowork and chat are merging into one Claude, together
with the launch of Claude Docs and Claude Slides and Claude Design working inside conversations.

## When is it useful?
- When deciding where a task should go (it now goes in any conversation).
- When handing over a report or deck to be finished while you are away.
- When a Cowork user or an admin asks what changes and when.

## Key points
- Quick questions and bigger hand-offs go to the same Claude, which can keep working after you close
  your laptop; it uses the context, skills, and connectors you already have.
- Claude Docs (write together), Claude Slides (Claude drafts; edit, present, download as PowerPoint or
  PDF), and Claude Design in conversations; each output lives at one shareable link.
- Check-in mode: by default Claude asks before acting; you can let it keep working and check in only
  when needed.
- Recurring work can be scheduled (e.g. a report every Monday).
- Rollout: Pro and Max first on web, desktop, mobile; Team and Free soon; Enterprise admins get at
  least 30 days notice. Docs, Slides, Design are beta on paid plans; Enterprise admins choose when to
  enable them. Cowork content stays where it was.
