## この記事について
2026年9月16日、Claude Cowork とチャットが1つの Claude に統合されるという発表です。Claude Docs と
Claude Slides の提供開始、会話の中で Claude Design が使えるようになったことも含まれます。

## どんなときに役立つか
- タスクをどこで進めるか迷ったとき(今はどの会話からでも可能)。
- 不在の間にレポートやスライドの仕上げを任せたいとき。
- Cowork ユーザーや管理者が、何がいつ変わるのかを尋ねるとき。

## 主なポイント
- ちょっとした質問も大きな仕事も同じ Claude に任せられ、ノートPCを閉じた後も作業を続けられます。
  既存のコンテキスト、スキル、コネクタをそのまま使います。
- Claude Docs(一緒に執筆)、Claude Slides(Claude が下書き。直接編集、発表、PowerPoint または PDF で
  ダウンロード)、会話内の Claude Design。成果物はそれぞれ1つの共有リンクにまとまります。
- 確認モード: 既定では行動前に確認。必要なときだけ確認しながら作業を続けさせることもできます。
- 繰り返しの作業はスケジュール可能(例: 毎週月曜のレポート)。
- 提供: まず Pro・Max にウェブ・デスクトップ・モバイルで。Team・Free は近日。Enterprise 管理者には
  少なくとも30日前に通知。Docs・Slides・Design は有料プランのベータで、Enterprise では管理者が有効化の
  時期を選びます。Cowork の内容はそのまま残ります。
