# Weekly report hand-off (from the announcement's scenario)

## Situation
A weekly report is due at noon. Before leaving home, the user hands it to Claude.

## Hand-off prompt template
```
What moved in the pipeline last week?
Write it the way we always do, flag anything that slipped, and put the highlights
in five slides for the leadership meeting.
```
Adapt: replace "pipeline" with your data source, "five slides" and "leadership meeting" with your
audience and format.

## What happens next (per the post)
1. If something is unclear, Claude asks.
2. The user checks progress from a phone on the way to the office.
3. At the desk: the report is a doc with notes from a teammate; the slides are ready to open, adjust,
   and download as PowerPoint.
4. Both came from the same conversation, so the slides match the report.
5. The user fixes a line directly, leaves a comment for Claude on a slide, and shares the link.
6. Scheduling it for every Monday makes Claude start on the report without being asked.
