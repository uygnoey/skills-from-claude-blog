## 이 글이 뭔가요
2026년 9월 16일, Claude Cowork 와 채팅이 하나의 Claude 로 합쳐진다는 발표입니다. Claude Docs 와
Claude Slides 출시, 그리고 대화 안에서 Claude Design 을 쓸 수 있게 된 소식도 함께 담겼습니다.

## 언제 유용한가요
- 작업을 어디서 해야 할지 고민될 때(이제 어떤 대화에서든 됩니다).
- 자리를 비운 사이 보고서나 발표 자료를 맡기고 싶을 때.
- Cowork 사용자나 관리자가 무엇이 언제 바뀌는지 물을 때.

## 핵심 포인트
- 간단한 질문도, 큰 작업도 같은 Claude 에 맡기며, 노트북을 닫은 뒤에도 작업을 이어갈 수 있습니다.
  이미 가진 컨텍스트, 스킬, 커넥터를 그대로 씁니다.
- Claude Docs(함께 작성), Claude Slides(Claude 가 초안 작성, 직접 편집·발표·PowerPoint 또는 PDF
  다운로드), 대화 안의 Claude Design. 모든 결과물은 공유 가능한 링크 하나에 있습니다.
- 확인 방식: 기본은 행동 전에 묻기. 계속 진행하다 살펴볼 일이 있을 때만 확인하도록 바꿀 수 있습니다.
- 반복 작업은 예약할 수 있습니다(예: 매주 월요일 보고서).
- 배포: Pro·Max 먼저 웹·데스크톱·모바일에, Team·Free 는 곧, Enterprise 관리자는 최소 30일 전에
  통지받습니다. Docs·Slides·Design 은 유료 플랜 베타이며 Enterprise 관리자가 켤 시점을 정합니다.
  Cowork 의 내용은 그대로 남아 있습니다.
