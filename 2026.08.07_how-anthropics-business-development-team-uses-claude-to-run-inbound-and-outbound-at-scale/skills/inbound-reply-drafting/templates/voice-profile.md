# Voice profile

The post describes "a profile of the rep's writing style (which each of us also
creates using a voice skill that reads through documents, messages, and emails
we have written)," so that "drafts arrive sounding like the sender."

This template captures what such a profile holds. The post does not publish the
profile format; the inputs it names — the rep's own documents, messages, and
emails — are the part to follow exactly.

---

## How to build it

Run a voice skill over material this person actually wrote:

- documents they authored,
- internal messages,
- customer emails they sent.

Have it report the patterns rather than adjectives — "opens with the answer,
then context" beats "clear and friendly."

## Keeping it current

Re-run the voice skill periodically over recent sends. Writing style drifts, and
a profile built from last year's emails drafts like last year.
