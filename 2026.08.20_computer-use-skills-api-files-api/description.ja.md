## この記事について
一般提供（GA）の発表。コンピュータ使用（computer use）、Skills API、Files API が Claude Platform で一般提供となり、コンピュータ使用にはウェブアプリケーションで動作するエージェント向けの新しいブラウザ使用（browser use）ツールが加わった。これらを合わせると、ソフトウェアを操作し、チームの専門性を適用し、完成したファイルを返すエージェントを構築できる、というのが記事の枠組みだ。すでに一般提供されていたコード実行とウェブ検索も同じループに収まる。

各要素の用途も説明されている。コンピュータ使用は、スクリーンショットを与えられたエージェントが見えているソフトウェアを操作するもので、だからこそ自動化を前提に作られていないアプリケーションでも動く。ブラウザ使用ツールはページ構造を加え、画面上の位置ではなく特定のフィールドやボタンを対象に動作させる。スキルは指示・スクリプト・テンプレートを収めたフォルダで、タスクが必要としたときにのみ読み込まれ、Skills API でアップロード・バージョン管理し、Claude のコード実行サンドボックスで動く。Files API はエージェントが読み書きする文書を保存し、リクエスト間で ID により参照できるようにする。

## どんなときに役立つか
- エージェントが API を提供していないアプリケーションやポータルの中で作業しなければならないとき。
- ウェブのタスクに対して、ピクセルベースのコンピュータ使用と構造を認識するブラウザ使用ツールのどちらを使うか決めるとき。
- チームの手順がプロンプト文字列の中で膨らみ続け、バージョン管理された成果物に移すべきとき。
- 複数ターンのワークフローが毎リクエストで同じ元文書を送り直しているとき。
- 成果物がレスポンステキストの一段落ではなくファイルであるとき。
- 既存のベータ統合を移行するにあたり、GA で何が変わったかを知りたいとき。

## 主なポイント
- **1ターンで複数アクション。** 更新されたコンピュータ使用ツールは、モデル呼び出しごとに1アクションではなく1ターンで複数アクションを実行するため、より少ない呼び出しと短い時間でタスクが完了する。ブラウザ使用ツールも同じ複数アクションのターンを用い、そこにページ構造を加える。
- **コンピュータ使用が HIPAA 規制対象ワークロードに利用可能になった** — Anthropic の BAA のもとで。
- **Skills API:** 自分のスキルをアップロードしてバージョン管理するための、よりシンプルな API。スキルは Claude のコード実行サンドボックスで動くため、自前でホストするものはない。
- **Files API:** ファイルの自動失効、5倍に引き上げられたレート制限、組織あたり 1 TB のストレージ。
- **組み合わせたループ。** 例として挙がるのは保険金請求エージェントだ。Files API から受付文書を読み、チームの申請手順を符号化したスキルに従い、ブラウザ使用ツールで保険会社のウェブポータル上の提出を完了し、確認書をファイルとして保存し直す。
- **新しいコンピュータ使用ツールで報告された結果。** API のない医療・保険システムの中で動作するエージェントについて、最長の請求ワークフローが32分から13分になり、テストしたすべてのワークフローでタスクあたりコストが約30%低下し、完了率は100%に達した。プロンプトの変更はなかった。
- **カスタマイズ面としてのスキル。** Box は Skills API で Box Agent に特化した文書作成機能を組み込んだ。銀行の与信メソドロジーと承認済みメモ形式をスキルが収め、Box Agent がそれを Box にすでにある文書に適用して、アナリストレビュー用の出典に基づく与信メモを作成する。複雑なワークフロー向けのエージェントを一つずつゼロから作らずに済む、という点が示されている。
- **提供状況。** Skills API と Files API は Microsoft Foundry でも利用でき、更新版のコンピュータ使用とブラウザ使用は Google Cloud の Vertex AI に近日提供される。既存のベータ統合は移行中もそのまま動作する。
