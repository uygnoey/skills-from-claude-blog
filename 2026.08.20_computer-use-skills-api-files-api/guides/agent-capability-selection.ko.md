# 프로덕션 에이전트를 위한 기능 선택

2026-08-20자로 컴퓨터 사용(computer use), Skills API, Files API가 Claude
플랫폼에서 정식 출시(GA)되었고, 컴퓨터 사용에는 새로운 브라우저 사용(browser use)
도구가 추가되었다. 이 가이드는 그중 무엇을 언제 고르는지에 관한 것이다.

## 이번 릴리스가 답하는 세 가지 질문

실제 업무를 하는 에이전트는 보통 모델 외에 세 가지가 더 필요하다.

1. **API가 없는 소프트웨어를 조작할 수단.** → 컴퓨터 사용, 웹에서는 브라우저 사용
   도구.
2. **팀의 전문성을 실행에 실어 나를 수단.** → Skills API.
3. **여러 턴에 걸쳐 문서를 보관하고 완성된 산출물을 돌려줄 수단.** → Files API.

이미 GA였던 코드 실행과 웹 검색도 같은 루프 안에 들어간다.

## 소프트웨어를 조작하기

**컴퓨터 사용**은 눈으로 보는 소프트웨어를 조작하는 에이전트를 만든다.
스크린샷이 주어지면 에이전트는 사람이 키보드 앞에서 하듯 클릭하고, 입력하고,
스크롤한다. 바로 그 점이, 애초에 자동화를 염두에 두지 않고 만들어진 애플리케이션
에서도 동작하게 해 준다.

이번에 추가된 **브라우저 사용 도구**는 이를 웹으로 확장한다. 스크린샷과 함께
에이전트가 페이지의 구조를 읽고, 화면상의 좌표가 아니라 특정 필드나 버튼을 대상으로
동작한다.

선택 순서:

| 상황 | 선택 |
| --- | --- |
| 실제 API가 존재함 | API를 쓴다 — 더 싸고, 더 빠르고, 결정론적이다 |
| 웹 애플리케이션, API 없음 | 브라우저 사용 도구 |
| 데스크톱 등 비브라우저 화면, API 없음 | 컴퓨터 사용 |

두 도구 모두 이제 모델 호출당 한 번의 동작이 아니라 **턴당 여러 동작**을 수행하므로,
더 적은 호출과 더 짧은 시간에 작업이 끝난다.

**왜 좌표보다 구조인가.** 이름이 지정된 요소를 대상으로 하면 레이아웃 변경, 해상도
차이, 컨트롤을 몇 픽셀 움직이는 리렌더링을 견뎌 낸다. 웹에서는 구조 기반 접근이
곧 신뢰성의 향상이며, 턴당 다중 동작을 포기하지 않아도 된다.

## 전문성을 실어 나르기

**스킬(Skill)** 은 지시문, 스크립트, 템플릿이 담긴 폴더이며, 작업이 필요로 할 때만
Claude가 불러온다. Skills API를 쓰면 자기 스킬을 업로드하고 버전 관리한 뒤 어떤
요청에도 붙일 수 있다. 스킬은 Claude의 코드 실행 샌드박스에서 돌아가므로 직접
호스팅할 것이 없다.

이 구조에서 세 가지가 따라 나온다.

- **필요할 때만 로드된다.** 인코딩한 전문성이 매 요청 프롬프트의 자리를 두고 경쟁할
  필요가 없다.
- **버전 관리된다.** 절차가 이를 호출하는 애플리케이션 코드와 분리된 자체 변경
  이력을 갖는다. 지난 분기에 누군가 고친 프롬프트 문자열과, 버전이 붙은 산출물의
  차이다.
- **스킬이 곧 커스터마이즈 지점이다.** Box의 사례가 가장 분명하다. 워크플로마다
  맞춤 에이전트를 새로 만드는 대신, 하나의 Box Agent에 회사별 여신 방법론과 승인된
  메모 형식을 담은 스킬을 붙인다.

## 문서를 보관하기

**Files API**는 에이전트가 읽고 쓰는 문서의 저장소다. PDF나 스프레드시트를 한 번
업로드하고 이후 요청에서는 다시 보내는 대신 ID로 참조하며, 에이전트가 만든 파일을
내려받는다. GA와 함께 파일 자동 만료, 5배 높아진 레이트 리밋, 조직당 1TB 저장 공간이
추가됐다.

설계를 바꾸는 것은 ID 참조다. 여러 턴에 걸친 워크플로가 매 요청마다 같은 원본
문서를 다시 전송하지 않게 되고, 산출물은 응답 텍스트에서 파싱해 내는 것이 아니라
가져오는 산출물이 된다.

## 조합된 루프

원문의 예시 — 클레임 처리 에이전트:

1. Files API에서 접수 문서를 읽는다.
2. 팀의 접수 절차를 담은 스킬을 따른다.
3. 브라우저 사용 도구로 보험사 웹 포털에서 제출을 완료한다.
4. 확인서를 다시 파일로 저장한다.

자신의 에이전트도 같은 네 질문을 순서대로 밟아 범위를 잡으면 된다. 무엇을 읽는가,
누구의 절차를 따르는가, 어떤 소프트웨어를 조작해야 하는가, 무엇을 돌려주는가.

## 보고된 결과

- **API가 없는 의료·보험 시스템.** 새 컴퓨터 사용 도구에서 한 팀의 가장 긴 클레임
  워크플로가 32분에서 13분으로 줄었고, 테스트한 모든 워크플로에서 작업당 비용이 약
  30% 감소했으며, 완료율은 100%에 도달했다. 프롬프트는 전혀 바꾸지 않았다.
- **Box.** 은행의 여신 방법론과 승인된 메모 형식을 스킬이 담고, Box Agent가 이를
  이미 Box에 있는 재무제표와 딜 문서에 적용해 애널리스트 검토용의 출처 기반 여신
  메모를 만든다.

두 번째 사례의 경계에 주목할 만하다. 산출물은 *애널리스트 검토용*이다. 오류가 곧
컴플라이언스 사건이 되는 영역에서, 에이전트의 역할은 검토 가능한 산출물까지다.

## 제공 현황

| 환경 | 상태 |
| --- | --- |
| Claude 플랫폼 | 컴퓨터 사용, 브라우저 사용 도구, Skills API, Files API |
| Microsoft Foundry | Skills API, Files API |
| Google Cloud Vertex AI | 업데이트된 컴퓨터 사용 및 브라우저 사용 도구 곧 제공 |

컴퓨터 사용은 이제 Anthropic BAA 하에서 HIPAA 규제 워크로드에 사용할 수 있다.
기존 베타 연동은 마이그레이션하는 동안 계속 동작한다. 시작하려면 컴퓨터 사용,
브라우저 사용 도구, Skills API, Files API의 플랫폼 문서를 참고하라.
