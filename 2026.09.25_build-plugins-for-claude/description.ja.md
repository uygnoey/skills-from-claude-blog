## この記事について
Anthropic が、開発者が Claude 向けのサードパーティ拡張を作る主な手段としてプラグインを開放した
という発表です。プラグインは MCP コネクタ、Agent Skills、またはその両方をまとめたもので、承認された
プラグインは Claude ディレクトリに掲載されます。有料の Claude プランの開発者向けに提出ポータルが
公開されました。

## どんなときに役立つか
- MCP コネクタ単体を出すか、プラグインバンドル全体を出すかを決めるとき。
- 提出を準備しながら、審査で何が確認されるかを知りたいとき。
- 公開後の掲載ページの成果をどう測るか計画するとき。

## 主なポイント
- 提出経路は二つ: 単一の MCP コネクタ(リモート MCP サーバーを指定)か、GitHub でホストする MCP
  サーバーとスキルのプラグインバンドル。Claude Code のバンドルには LSP、コマンド、フック、
  エージェントも含められます。
- 提出時に自動検証と安全スキャンが行われ、ポータルで審査状況・スキャン結果・推奨される修正を確認
  できます。承認後、公開のタイミングは開発者が選びます。
- 分析: 製品サーフェス別・バージョン別のインストール数、掲載ページの閲覧数とそこにつながった検索。
- 最新の MCP 仕様(ステートレスなコア)に加え、MCP Apps(チャット内のインタラクティブ UI)と
  Enterprise Managed Auth(エンタープライズユーザー向けのゼロタッチ OAuth)に対応。
- Claude と Claude Code で一つの発見体験が展開予定。既存のスキル・コネクタ・プラグインは変更不要で、
  今後コネクタの掲載をプラグインに切り替えられるようになります。

## 同梱リソース
- スキル: `plugin-directory-submission` — 提出経路の選択、審査の流れ、公開、分析、MCP 2.0 拡張
  (`references/submission-portal.md`)。
