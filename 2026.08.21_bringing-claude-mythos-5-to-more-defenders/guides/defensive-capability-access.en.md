# Bringing frontier cyber defense capability to more defenders

Claude Mythos 5 is now available in Claude Security, and coming soon to partners' cyber defense
tools. Alongside that, a $35M fund for open-source security and an expansion of the Cyber
Verification Program.

## The problem this design solves

In April, Project Glasswing put Claude Mythos Preview — and its successor, Claude Mythos 5 — in
the hands of a small group of organizations securing the world's most critical software. The point
was timing: give defenders a window to find and fix vulnerabilities ahead of models with similar
capabilities becoming generally available or reaching malicious actors.

Expanding that window to more defenders needs safety classifiers and safeguards that let
Mythos-class capability reach defenders without putting its offensive cyber capabilities in the
wrong hands. Claude Fable 5 was the first step: broadly available, with dual-use cyber work
blocked.

The next step turns on a distinction about interaction shape:

> The riskiest behavior occurs when a user has direct access to a model, where a malicious actor
> can try to steer it toward harmful uses. But if users can only receive specific outputs, such as
> a patch for a vulnerability or a security alert, that risk is much lower.

Every access path below gives defenders greater access to the defensive *results* while keeping
guardrails around direct access to the model.

## 1. Mythos inside the tools defenders already run

The teams defending hospitals, utilities, financial systems, and the software supply chain already
rely on a suite of products and services for security operations, incident response, threat
intelligence, and detection engineering. The fastest way to make frontier capability available to
them is to integrate Mythos-class models into those tools.

Many partners have already built cyber products on Claude Opus that help security teams triage
alerts, identify threats, and remediate vulnerabilities faster. Anthropic is now working with these
partners and more to build Claude Mythos 5 into their products and services, so they can deliver
Mythos-level defensive outcomes to their customers.

**The interaction shape matters.** An end user of one of these products is not interacting with
Mythos directly. They work through a purpose-built interface that runs Mythos in the background for
a defined task, and receive only the specific artifact the product is intended to provide. A
vulnerability-remediation tool might return a list of suggested patches — generated by Mythos, with
no way for the user to prompt the model to develop an exploit. Anthropic and its partners also have
abuse prevention measures in place to verify the model stays within its intended scope.

This work is early and expected to expand. Builders of security products and services can register
their interest.

## 2. Claude Security scans on Claude Mythos 5

Claude Security scans codebases for vulnerabilities and suggests patches for human review. It is in
public beta for Claude Enterprise customers, and scans with Mythos 5 bill as standard token usage
under your existing plan, with no separate add-on.

The workflow:

1. **Enable.** An enterprise admin turns on Claude Security in the admin console.
2. **Scan.** From `claude.ai/security`, select a repository to scan using Claude Mythos 5.
3. **Read the findings.** Each returns with a CWE (Common Weakness Enumeration) category,
   confidence and severity ratings, and a suggested fix.
4. **Patch.** Open Claude Code on the web to implement the fix. Interactive patching uses the models
   your organization has access to in Claude Code — the Mythos scan does not extend Mythos access to
   other surfaces.
5. **Approve.** Every patch must be reviewed and approved by a human before it can be implemented.

Claude Security uses Mythos 5 to scan code you own, and returns detailed findings rather than raw
outputs, without exposing the model itself. Defenders get the capabilities of Claude Mythos 5
without the model becoming accessible to those who might misuse it.

## 3. The Defender Advantage Fund (0xDAF)

Some of the world's most widely used programs run on open-source software. Yet these projects are
often maintained by volunteers or nonprofit foundations who may lack the resources or personnel to
comprehensively defend them against attack.

Through Project Glasswing, Anthropic made $4M in direct donations to open-source security
organizations, provided credits to the open-source security foundations in the program, helped scan
and patch widely used projects, and supported coordinated vulnerability-fixing efforts like Akrites
and Gold Eagle.

The Defender Advantage Fund builds on that with **$35 million in Claude credits** for organizations
helping open-source maintainers secure their software. Grants focus on three areas:

- patching live vulnerabilities in widely used projects;
- automating scanning and patching in ways other projects can replicate;
- helping projects pursue more ambitious security approaches that make them resistant to whole
  classes of attack.

The fund starts with a small number of larger, pilot grants to learn what works and scales best.
Initial recipients are to be announced.

## 4. Expanding the Cyber Verification Program

The Cyber Verification Program gives organizations access to dual-use capabilities on Claude Opus
and Sonnet models. Accepted teams experience reduced safeguards, minimizing interruptions for
legitimate cybersecurity work on systems they are authorized to protect.

Over the coming weeks the program evolves to expand safeguarded access to Claude Mythos: access to
defensive capabilities like vulnerability triaging and validation will expand to Mythos-class
models, and cyber defenders will see reduced blocks on Opus- and Sonnet-class models.

In parallel, access to Claude Mythos continues to expand through Project Glasswing in collaboration
with U.S. Government partners, focused on protectors of critically important infrastructure that
meet strict security control requirements.

Security teams performing legitimate cybersecurity work are encouraged to apply now for reduced
safeguards on Opus and Sonnet. Teams already enrolled and accepted need take no action.

## Which path applies to you

| Situation | Path |
|---|---|
| You own the codebase and are on Claude Enterprise | Claude Security scan |
| You build security products or services for other defenders | Partner integration — register interest |
| You help open-source maintainers and need resourcing | Defender Advantage Fund |
| You need reduced safeguards on direct model use for authorized defensive work | Cyber Verification Program |

## What's next

These initiatives continue an effort to make the defensive capabilities of frontier models
available to more people and organizations, and to support the open-source community in hardening
their projects. The stated direction is continued work with government partners, organizations,
open-source maintainers, and the broader industry to build the resilient cyber infrastructure
today's highly capable AI models demand.
