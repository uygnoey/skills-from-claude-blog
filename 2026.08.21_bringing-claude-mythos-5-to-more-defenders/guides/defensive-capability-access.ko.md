# 프런티어 사이버 방어 역량을 더 많은 방어자에게

Claude Mythos 5를 이제 Claude Security에서 사용할 수 있으며, 파트너들의 사이버 방어 도구에도 곧 들어갑니다.
여기에 더해 오픈소스 보안을 위한 3,500만 달러 규모 펀드와 Cyber Verification Program 확대가 함께 발표되었습니다.

## 이 설계가 푸는 문제

4월에 Project Glasswing은 Claude Mythos Preview와 그 후속인 Claude Mythos 5를, 세계에서 가장 중요한
소프트웨어를 지키는 소수 조직의 손에 쥐어 줬습니다. 핵심은 타이밍이었습니다. 유사한 역량의 모델이 일반에
공개되거나 악의적 행위자에게 닿기 전에, 방어자가 취약점을 찾아 고칠 시간을 확보하는 것입니다.

그 시간 창을 더 많은 방어자에게 넓히려면, Mythos급 역량이 공격적 사이버 능력을 엉뚱한 손에 쥐어 주지 않으면서
방어자에게 도달하게 하는 안전 분류기와 안전장치가 필요합니다. Claude Fable 5가 그 첫걸음이었습니다. 널리
제공하되 이중 용도(dual-use) 사이버 작업은 차단하는 방식이었습니다.

다음 단계는 상호작용의 형태에 관한 구분에서 출발합니다.

> 가장 위험한 행위는 사용자가 모델에 직접 접근할 때 발생합니다. 악의적 행위자가 모델을 해로운 용도로
> 유도하려 시도할 수 있기 때문입니다. 하지만 사용자가 취약점 패치나 보안 경보 같은 특정 산출물만 받을 수
> 있다면 그 위험은 훨씬 낮아집니다.

아래의 모든 접근 경로는 모델에 대한 직접 접근에는 적절한 가드레일을 유지하면서, 방어적 *결과물*에 대한
접근은 넓혀 줍니다.

## 1. 방어자가 이미 쓰는 도구 안의 Mythos

병원, 전력·수도, 금융 시스템, 소프트웨어 공급망을 지키는 팀들은 이미 보안 운영, 사고 대응, 위협 인텔리전스,
탐지 엔지니어링을 위한 제품과 서비스를 쓰고 있습니다. 그들에게 프런티어 역량을 전달하는 가장 빠른 길은
그 도구들 안에 Mythos급 모델을 통합하는 것입니다.

많은 파트너가 이미 Claude Opus 위에 사이버 제품을 만들어, 보안 팀이 경보를 분류하고 위협을 식별하고 취약점을
더 빠르게 수정하도록 돕고 있습니다. Anthropic은 이제 이 파트너들과 그 이상의 파트너들과 함께 Claude Mythos 5를
그들의 제품·서비스에 통합해, 고객에게 Mythos 수준의 방어 결과를 전달하도록 협업하고 있습니다.

**상호작용의 형태가 중요합니다.** 이런 제품의 최종 사용자는 Mythos와 직접 상호작용하지 않습니다. 정해진
작업을 위해 백그라운드에서 Mythos를 돌리는 목적 특화 인터페이스를 통해 작업하고, 그 제품이 제공하도록 설계된
특정 산출물만 받습니다. 취약점 수정 도구라면 제안 패치 목록을 돌려주는 식이며, 이는 Mythos가 생성했지만
사용자가 모델에게 익스플로잇을 만들라고 프롬프트할 방법은 없습니다. Anthropic과 파트너들은 모델이 의도된
범위 안에 머무르는지 확인하는 오남용 방지 조치도 함께 두고 있습니다.

이 작업은 아직 초기이며 시간이 지나며 확대될 예정입니다. 보안 제품·서비스를 만드는 곳은 관심 등록이 가능합니다.

## 2. Claude Mythos 5로 실행되는 Claude Security 스캔

Claude Security는 코드베이스에서 취약점을 스캔하고 사람이 검토할 패치를 제안합니다. 현재 Claude Enterprise
고객 대상 퍼블릭 베타이며, Mythos 5 스캔은 기존 플랜의 표준 토큰 사용량으로 과금되고 별도 애드온은 없습니다.

워크플로:

1. **활성화.** 엔터프라이즈 관리자가 admin console에서 Claude Security를 켭니다.
2. **스캔.** `claude.ai/security`에서 Claude Mythos 5로 스캔할 리포지토리를 선택합니다.
3. **발견 사항 확인.** 각 항목은 CWE(Common Weakness Enumeration) 분류, 신뢰도·심각도 등급, 제안 수정안과
   함께 반환됩니다.
4. **패치.** 웹의 Claude Code를 열어 수정을 구현합니다. 인터랙티브 패치는 조직이 Claude Code에서 접근 권한을
   가진 모델을 사용합니다. Mythos 스캔이 다른 표면으로 Mythos 접근을 확장해 주지는 않습니다.
5. **승인.** 모든 패치는 구현되기 전에 반드시 사람이 검토하고 승인해야 합니다.

Claude Security는 Mythos 5로 여러분이 소유한 코드를 스캔하고, 원시 출력이 아니라 상세한 발견 사항을 돌려주며
모델 자체를 노출하지 않습니다. 방어자는 Claude Mythos 5의 역량을 얻되, 모델이 오용할 수 있는 이들에게
접근 가능해지지는 않습니다.

## 3. Defender Advantage Fund (0xDAF)

세계에서 가장 널리 쓰이는 프로그램 중 상당수가 오픈소스 소프트웨어 위에서 돌아갑니다. 그러나 이런 프로젝트는
자원봉사자나 비영리 재단이 유지보수하는 경우가 많고, 공격에 종합적으로 대응할 자원이나 인력이 부족할 수 있습니다.

Project Glasswing을 통해 Anthropic은 오픈소스 보안 조직에 400만 달러를 직접 기부하고, 프로그램 내 오픈소스
보안 재단들에 크레딧을 제공했으며, 널리 쓰이는 프로젝트의 스캔·패치를 도왔고, Akrites와 Gold Eagle 같은 조정된
취약점 수정 노력을 지원했습니다.

Defender Advantage Fund는 그 위에 **3,500만 달러 상당의 Claude 크레딧**을 더해, 오픈소스 메인테이너의 보안을
돕는 조직을 지원합니다. 지원금은 세 영역에 집중됩니다.

- 널리 쓰이는 프로젝트의 실제 취약점 패치;
- 다른 프로젝트가 복제할 수 있는 방식으로 스캔·패치 자동화;
- 공격의 한 부류 전체에 내성을 갖게 하는, 더 야심 찬 보안 접근을 프로젝트가 추구하도록 지원.

펀드는 무엇이 효과적이고 잘 확장되는지 배우기 위해 소수의 큰 파일럿 지원금으로 시작합니다. 초기 수혜 대상은
추후 공개 예정입니다.

## 4. Cyber Verification Program 확대

Cyber Verification Program은 Claude Opus와 Sonnet 모델에서 이중 용도 역량에 대한 접근을 조직에 제공합니다.
승인된 팀은 안전장치가 완화되어, 자신들이 보호 권한을 가진 시스템에 대한 정당한 보안 작업에서 중단이 줄어듭니다.

앞으로 몇 주에 걸쳐 프로그램은 Claude Mythos로 안전장치가 적용된 접근을 확대하는 방향으로 진화합니다. 취약점
분류와 검증 같은 방어 역량 접근이 Mythos급 모델로 확대되고, 사이버 방어자는 Opus·Sonnet급 모델에서 차단이
줄어드는 것을 보게 됩니다.

동시에 Claude Mythos 접근은 미국 정부 파트너와 협력하는 Project Glasswing을 통해 계속 확대되며, 엄격한 보안
통제 요건을 충족하는 핵심 인프라 보호 주체에 초점을 맞춥니다.

정당한 보안 업무를 수행하는 팀은 지금 Opus와 Sonnet의 완화된 안전장치를 위해 프로그램에 지원하도록 권장됩니다.
이미 등록·승인된 팀은 별도 조치가 필요 없습니다.

## 어떤 경로가 맞나요

| 상황 | 경로 |
|---|---|
| 코드베이스를 소유하고 Claude Enterprise를 쓰는 경우 | Claude Security 스캔 |
| 다른 방어자를 위한 보안 제품·서비스를 만드는 경우 | 파트너 통합 — 관심 등록 |
| 오픈소스 메인테이너를 돕고 자원이 필요한 경우 | Defender Advantage Fund |
| 승인된 방어 업무를 위해 직접 모델 사용에 완화된 안전장치가 필요한 경우 | Cyber Verification Program |

## 다음 단계

이 이니셔티브들은 프런티어 모델의 방어 역량을 더 많은 사람과 조직에 제공하고, 오픈소스 커뮤니티가 프로젝트를
견고하게 만들도록 지원하려는 노력의 연장선입니다. 밝힌 방향은 정부 파트너, 조직, 오픈소스 메인테이너, 그리고
업계 전반과 계속 협력해, 오늘날의 고성능 AI 모델이 요구하는 회복력 있는 사이버 인프라를 구축하는 것입니다.
