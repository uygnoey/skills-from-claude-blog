# フロンティアのサイバー防御能力をより多くの防御側へ

Claude Mythos 5 が Claude Security で利用可能になり、パートナーのサイバー防御ツールにも近く搭載されます。
あわせて、オープンソースセキュリティのための 3,500 万ドル規模のファンドと、Cyber Verification Program の
拡大が発表されました。

## この設計が解く問題

4 月、Project Glasswing は Claude Mythos Preview と、その後継である Claude Mythos 5 を、世界で最も重要な
ソフトウェアを守る少数の組織の手に届けました。狙いはタイミングです。同等の能力を持つモデルが一般提供され
たり悪意ある行為者に渡ったりする前に、防御側が脆弱性を見つけて直すための時間を確保することでした。

その時間の窓をより多くの防御側に広げるには、Mythos 級の能力が攻撃的なサイバー能力を誤った手に渡すことなく
防御側に届くようにする、安全分類器とセーフガードが必要です。Claude Fable 5 がその第一歩でした。広く提供
しつつ、デュアルユースのサイバー作業はブロックする形です。

次の一歩は、相互作用の「形」に関する区別から出発します。

> 最もリスクが高いのは、ユーザーがモデルに直接アクセスできる場合です。悪意ある行為者がモデルを有害な用途へ
> 誘導しようと試みうるからです。しかしユーザーが受け取れるのが、脆弱性のパッチやセキュリティアラートといった
> 特定の出力だけであれば、そのリスクははるかに低くなります。

以下のすべてのアクセス経路は、モデルへの直接アクセスには適切なガードレールを保ちながら、防御的な*結果*への
アクセスを広げます。

## 1. 防御側がすでに使うツールの中の Mythos

病院、公益インフラ、金融システム、ソフトウェアサプライチェーンを守るチームは、すでにセキュリティ運用、
インシデント対応、脅威インテリジェンス、検知エンジニアリングのための製品群を使っています。フロンティアの
能力を彼らに届ける最短経路は、そのツールに Mythos 級モデルを統合することです。

多くのパートナーはすでに Claude Opus 上にサイバー製品を構築し、セキュリティチームがアラートをトリアージし、
脅威を特定し、脆弱性をより速く修正するのを支援しています。Anthropic はいま、これらのパートナーとさらに多くの
パートナーとともに Claude Mythos 5 を製品・サービスに組み込み、顧客に Mythos 水準の防御的成果を届けられる
ようにしています。

**相互作用の形が重要です。** これらの製品のエンドユーザーは Mythos と直接やり取りしません。定義されたタスクの
ために背後で Mythos を実行する専用インターフェースを通して作業し、その製品が提供するよう設計された特定の
成果物だけを受け取ります。脆弱性修正ツールなら、提案パッチの一覧を返すといった具合です。それは Mythos が
生成したものですが、ユーザーがモデルにエクスプロイトの開発を指示する手段はありません。Anthropic とパートナー
は、モデルが意図された範囲にとどまることを検証する不正利用防止策も講じています。

この取り組みはまだ初期段階で、今後拡大していく見込みです。セキュリティ製品・サービスを手がける事業者は関心を
登録できます。

## 2. Claude Mythos 5 で動く Claude Security スキャン

Claude Security はコードベースを脆弱性についてスキャンし、人間のレビュー用にパッチを提案します。現在は
Claude Enterprise 顧客向けのパブリックベータで、Mythos 5 でのスキャンは既存プランの標準的なトークン利用として
課金され、別途のアドオンはありません。

ワークフロー：

1. **有効化。** エンタープライズ管理者が admin console で Claude Security をオンにします。
2. **スキャン。** `claude.ai/security` から、Claude Mythos 5 でスキャンするリポジトリを選択します。
3. **結果を読む。** 各所見は CWE（Common Weakness Enumeration）カテゴリ、確信度と深刻度の評価、推奨される
   修正とともに返されます。
4. **パッチ。** ウェブ版 Claude Code を開いて修正を実装します。対話的なパッチ適用では、組織が Claude Code で
   アクセス権を持つモデルが使われます。Mythos によるスキャンが他のサーフェスへの Mythos アクセスを広げること
   はありません。
5. **承認。** すべてのパッチは、実装前に人間がレビューし承認しなければなりません。

Claude Security は Mythos 5 を使って自社所有のコードをスキャンし、生の出力ではなく詳細な所見を返します。
モデル自体は露出しません。防御側は Claude Mythos 5 の能力を得られる一方、モデルが悪用しうる者にアクセス可能に
なることはありません。

## 3. Defender Advantage Fund（0xDAF）

世界で最も広く使われているプログラムの一部はオープンソースソフトウェア上で動いています。しかしそうした
プロジェクトはボランティアや非営利財団が保守していることが多く、攻撃から包括的に守るための資源や人員を欠いて
いる場合があります。

Project Glasswing を通じて、Anthropic はオープンソースセキュリティ組織へ 400 万ドルを直接寄付し、プログラム
内のオープンソースセキュリティ財団にクレジットを提供し、広く使われるプロジェクトのスキャンとパッチ適用を支援し、
Akrites や Gold Eagle のような協調的な脆弱性修正の取り組みを支えてきました。

Defender Advantage Fund はその上に、オープンソースのメンテナがソフトウェアを守るのを助ける組織向けに
**3,500 万ドル相当の Claude クレジット**を積み増します。助成は三つの領域に焦点を当てます。

- 広く使われているプロジェクトの現行脆弱性へのパッチ適用；
- 他のプロジェクトが再現できる形でのスキャンとパッチ適用の自動化；
- 攻撃のクラス全体に耐性を持たせる、より野心的なセキュリティアプローチの追求支援。

ファンドは、何が有効でよくスケールするかを学ぶため、少数の大型パイロット助成から始まります。初期の受給先は
追って公表される予定です。

## 4. Cyber Verification Program の拡大

Cyber Verification Program は、Claude Opus および Sonnet モデルでのデュアルユース能力へのアクセスを組織に
提供しています。受け入れられたチームはセーフガードが緩和され、保護する権限を持つシステムに対する正当な
セキュリティ業務での中断が最小化されます。

今後数週間で、このプログラムは Claude Mythos への保護付きアクセスを広げる方向へ進化します。脆弱性のトリアージ
や検証といった防御的能力へのアクセスが Mythos 級モデルへ拡大し、サイバー防御側は Opus・Sonnet 級モデルでの
ブロックが減ることになります。

並行して、Claude Mythos へのアクセスは米国政府のパートナーと協力する Project Glasswing を通じて拡大が続き、
厳格なセキュリティ統制要件を満たす重要インフラの保護者に焦点が当てられます。

正当なサイバーセキュリティ業務を行うチームは、Opus と Sonnet でのセーフガード緩和のため、いまプログラムへ
申請することが推奨されています。すでに登録・受理済みのチームは対応不要です。

## どの経路が当てはまるか

| 状況 | 経路 |
|---|---|
| 自社所有のコードベースがあり Claude Enterprise を利用中 | Claude Security スキャン |
| 他の防御側向けにセキュリティ製品・サービスを構築している | パートナー統合 — 関心を登録 |
| オープンソースのメンテナを支援していて資源が必要 | Defender Advantage Fund |
| 認可された防御業務のためモデル直接利用のセーフガード緩和が必要 | Cyber Verification Program |

## 次に来るもの

これらの取り組みは、フロンティアモデルの防御能力をより多くの人と組織に届け、オープンソースコミュニティが
プロジェクトを堅牢化するのを支援する努力の延長線上にあります。示された方向性は、政府パートナー、組織、
オープンソースのメンテナ、そして業界全体と協働し続け、今日の高性能な AI モデルが要求する回復力あるサイバー
インフラを築くことです。
