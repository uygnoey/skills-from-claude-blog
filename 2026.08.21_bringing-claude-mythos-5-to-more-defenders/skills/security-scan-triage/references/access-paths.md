# Access paths to Mythos-class defensive capability

Four ways defenders reach frontier defensive capability, and what each one is for. The organizing
principle across all of them: **users receive specific outputs rather than direct model access.**
Direct access is where a malicious actor can try to steer a model toward harmful uses; receiving a
patch or an alert carries much lower risk.

## Background

In April, Anthropic launched **Project Glasswing** to put Claude Mythos Preview — and its
successor, Claude Mythos 5 — in the hands of a small group of organizations securing the world's
most critical software. This gave defenders a window of time to find and fix vulnerabilities ahead
of models with similar capabilities becoming generally available or reaching malicious actors.

**Claude Fable 5** was the first step toward broader reach: it made the model broadly available
while blocking dual-use cyber work. Safety classifiers and safeguards are what allow access to
Mythos-class models to expand without putting their offensive cyber capabilities in the wrong hands.

## 1. Partner-integrated cyber defense tools

Teams defending hospitals, utilities, financial systems, and the software supply chain already run
a suite of products for security operations, incident response, threat intelligence, and detection
engineering. The fastest way to get frontier capability to those defenders is to integrate
Mythos-class models into the tools they already use.

Many partners have already built cyber products on Claude Opus that help security teams triage
alerts, identify threats, and remediate vulnerabilities faster. Anthropic is now working with these
partners and more to build Claude Mythos 5 into their products and services.

**How the interaction is shaped:** the end user is not interacting with Mythos directly. They work
through a purpose-built interface that runs Mythos in the background for a defined task, and
receive only the specific artifact the product is intended to provide. A vulnerability-remediation
tool might output a list of suggested patches — generated by Mythos, with no way for the user to
prompt the model to develop an exploit. Anthropic and its partners also maintain abuse prevention
measures to verify the model stays within its intended scope.

**Status:** early, expected to expand over time. Security product and service builders can register
their interest in bringing Claude Mythos 5 to their customers.

## 2. Claude Security scans on Claude Mythos 5

**Who:** Claude Enterprise customers. Public beta.

**What:** scans codebases for vulnerabilities and suggests patches for human review.

**Enable:** enterprise admins turn on Claude Security in the admin console.

**Use:** from `claude.ai/security`, select a repository to scan using Claude Mythos 5. Each finding
returns with a CWE (Common Weakness Enumeration) category, confidence and severity ratings, and a
suggested fix.

**Patch:** open Claude Code on the web to implement the fix. Interactive patching uses the models
your organization has access to in Claude Code — the Mythos scan does not extend Mythos access to
other surfaces. **Every patch must be reviewed and approved by a human before it can be
implemented.**

**Billing:** scans with Mythos 5 bill as standard token usage under your existing plan, with no
separate add-on.

## 3. The Defender Advantage Fund (0xDAF)

**Who:** organizations helping open-source maintainers secure their software.

**What:** $35 million in Claude credits.

**Why:** some of the world's most widely used programs run on open-source software, yet these
projects are often maintained by volunteers or nonprofit foundations who may lack the resources or
personnel to comprehensively defend them.

**Grant focus areas:**

1. Patching live vulnerabilities in widely used projects.
2. Automating scanning and patching in ways other projects can replicate.
3. Helping projects pursue more ambitious security approaches that make them resistant to whole
   classes of attack.

**Precedent:** through Project Glasswing, Anthropic made $4M in direct donations to open-source
security organizations, provided credits to the open-source security foundations in the program,
helped scan and patch widely used projects, and supported coordinated vulnerability-fixing efforts
including Akrites and Gold Eagle.

**Rollout:** starting with a small number of larger, pilot grants to learn what works and scales
best; initial recipients to be announced.

## 4. The Cyber Verification Program

**Who:** vetted defenders doing legitimate cybersecurity work on systems they are authorized to
protect.

**What today:** access to dual-use capabilities on Claude Opus and Sonnet models, with reduced
safeguards that minimize interruptions for accepted teams.

**What is changing:** over the coming weeks the program expands safeguarded access toward Claude
Mythos. Access to defensive capabilities such as vulnerability triaging and validation will expand
to Mythos-class models, and cyber defenders will see reduced blocks on Opus- and Sonnet-class
models.

**Alongside it:** access to Claude Mythos continues to expand through Project Glasswing in
collaboration with U.S. Government partners, focused on protectors of critically important
infrastructure that meet strict security control requirements.

**What to do:** security teams performing legitimate cybersecurity work are encouraged to apply for
the program now for reduced safeguards on Opus and Sonnet. Organizations already enrolled and
accepted need take no action.

## Choosing among them

| Situation | Path |
|---|---|
| You own the codebase and are on Enterprise | Claude Security scan (2) |
| You build security products for other defenders | Partner integration (1) |
| You help open-source maintainers and need funding | Defender Advantage Fund (3) |
| You need reduced safeguards on direct model use for authorized defensive work | Cyber Verification Program (4) |
