## この記事について
フロンティアのサイバー防御能力を、より多くの防御側の手に届けるための進捗アップデートです。Claude Mythos 5 が Claude Security で利用可能になり、パートナーのサイバー防御ツールにも近く搭載されます。3,500 万ドル規模の Defender Advantage Fund がオープンソースのセキュリティ作業を支え、Cyber Verification Program は Mythos 級アクセスへと拡大します。

全体を貫く考え方は、モデルの大きさではなく相互作用の「形」です。モデルへの直接アクセスこそ、悪意ある行為者がモデルを有害な用途へ誘導しようとしうる場所です。ユーザーが受け取れるのが脆弱性のパッチやセキュリティアラートといった特定の出力だけなら、そのリスクははるかに低くなります。四つのアクセス経路はいずれも、モデルへの直接アクセスにガードレールを保ちつつ、防御的な*結果*へのアクセスを広げます。

## どんなときに役立つか
- どのアクセス経路が自分の状況に合うかを決めるとき：コードを自社所有しているか、セキュリティ製品を作っているか、オープンソースのメンテナを支援しているか、認可された防御業務にセーフガード緩和が必要か。
- エンタープライズ管理者が Claude Security を有効化し、チームにリポジトリスキャンを案内するとき。
- CWE カテゴリ、確信度と深刻度の評価、推奨修正とともに返ってきたスキャン結果をトリアージするとき。
- フロンティア能力の上に製品やワークフローを設計し、「モデルアクセスではなく特定の出力」という形を保つ必要があるとき。
- オープンソースプロジェクトが脆弱性のパッチ適用やスキャン自動化のための資源を必要としているとき。

## 主なポイント
- **相互作用の形こそが制御手段。**「ユーザーが受け取れるのが脆弱性のパッチやセキュリティアラートといった特定の出力だけなら、そのリスクははるかに低い」——直接アクセスとの対比です。
- **Project Glasswing**（4 月）は Mythos Preview と Mythos 5 を、世界で最も重要なソフトウェアを守る少数の組織に届け、同等の能力が広く行き渡る前の時間を防御側に確保しました。**Claude Fable 5** は広く提供しつつデュアルユースのサイバー作業をブロックした最初の広範な一歩です。
- **パートナー統合：** Mythos 5 が、防御側がすでに使うセキュリティ運用・インシデント対応・脅威インテリジェンス・検知エンジニアリングの製品に組み込まれつつあります。エンドユーザーは定義されたタスクのために背後で Mythos を動かす専用インターフェースを通じて作業し、意図された成果物だけを受け取ります。たとえば提案パッチは受け取れても、エクスプロイトを求めるプロンプトを送る手段はありません。不正利用防止策がモデルの範囲逸脱を検証します。
- **Claude Security のスキャンが Mythos 5 で動くようになりました。** Claude Enterprise 向けパブリックベータで、管理者が admin console で有効化し、`claude.ai/security` からリポジトリを選択します。所見は CWE カテゴリ、確信度と深刻度の評価、推奨修正とともに返ります。標準的なトークン利用として課金され、別途アドオンはありません。
- **パッチ適用には人間のゲートが残ります。** ウェブ版 Claude Code を開いて修正を実装します。対話的なパッチ適用は組織が Claude Code で持つモデルを使い（Mythos スキャンが他サーフェスへの Mythos アクセスを広げることはありません）、すべてのパッチは人間のレビューと承認を要します。
- **Defender Advantage Fund（0xDAF）：** オープンソースのメンテナを助ける組織向けに 3,500 万ドル相当の Claude クレジット。現行脆弱性へのパッチ適用、再現可能な形でのスキャン・パッチ自動化、攻撃のクラス全体に耐性を持たせる取り組みに焦点を当てます。Glasswing 下の 400 万ドルの直接寄付や Akrites・Gold Eagle のような協調的取り組みの上に築かれ、少数の大型パイロット助成から始まります。
- **Cyber Verification Program の拡大：** 検証済みの防御側はすでに Opus と Sonnet でセーフガードの緩和を受けています。今後数週間で、脆弱性のトリアージや検証といった防御能力が Mythos 級モデルへ拡大し、Opus・Sonnet 級ではブロックが減ります。厳格なセキュリティ統制要件を満たす重要インフラの保護者を対象に、米国政府パートナーとの Glasswing アクセスも継続します。
