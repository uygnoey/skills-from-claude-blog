## この記事について
2026年10月28日の発表記事です。60年以上の歴史を持つテクノロジーインテリジェンス企業 IDC が Anthropic と協力し、
IDC Quanta を MCP コネクタとして Claude に統合しました。IDC の顧客はすでに利用できます。IDC は社内全体にも
Claude を展開しています。

## どんなときに役立つか
- IDC Quanta を利用でき、長いレポートを読む代わりに完成した分析(ブリーフ、候補リスト、ベンチマーク)が
  欲しいとき。
- IDC の定義に一致し、出典付きの市場数値を Claude 上で使いたいとき。
- 全社的な Claude 導入を計画しており、リサーチ企業の具体的な順序と成果を参考にしたいとき。

## 主なポイント
- 顧客が取り組んでいる市場・戦略・購買案件を説明すると、IDC Quanta コネクタが IDC の予測、市場データ、
  リサーチに基づく分析を返します。ベンチマーク、市場規模の算定、ベンダー選定、戦略策定に使えます。
- シナリオ例: 戦略担当リードは丸1日かかっていた競合ブリーフを出典付きで数分で得ます。CIO は IDC データと
  MarketScape リサーチから選ばれた購買ソフトウェアの上位3ベンダーを Excel スコアカードで受け取ります。
  CFO は IT 予算をアップロードし、IDC の予測とどこでどれだけ違うかを確認します。アップロードしたデータは
  顧客だけの非公開データとして保たれます。
- Claude のデスクトップ・モバイルアプリ、Cowork、Microsoft Office アドインで動作します。Claude は IDC の
  アナリストと同じデータと定義を使い、回答ごとに IDC の出典を示します。
- 社内導入: 最初はエンジニアリングでした。エンジニアはアナリスト向けの社内リサーチデータリポジトリを、
  見積もり3か月のところ3週間で再構築し、テストに Claude Code を使い始めてから出荷コードのバグが大きく
  減りました。5日かかっていたコードレビューは約30分になりました。
- PM は Claude Code でプロトタイプを作り(エンジニアリングに渡るまで数か月 → 数週間)、Cowork が計画の
  草案を書きます(計画スプリント3週間 → 3日)。新しいテストの作成は約20分、Claude で作ったツールは CRM の
  エクスポートを読んで停滞した商談を示し、コンテンツアシスタントは SEO/AEO とバイヤーペルソナのチェックを
  経たマーケティング原稿を書き、人が編集します。
- IDC の CEO は、買収の影響分析が 150億を超えるデータポイントに基づき数分で済むようになったと述べています。
