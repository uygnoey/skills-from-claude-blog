# Request patterns for IDC Quanta in Claude

Fill in the brackets. The post's guidance is to describe the question you are working on and let Claude
answer it with IDC's intelligence; the wording below is a template, not text from the post.

## Competitive brief
```
I'm a [role] at [company]. Using IDC Quanta, write a competitor brief on [competitor] in [market].
Cover positioning, market share, product capabilities, and recent acquisitions.
Cite the IDC document or dataset behind each claim.
```

## Vendor shortlist
```
I'm evaluating [category, e.g. procurement software]. Our current architecture: [systems].
Our requirements: [requirements]. Using IDC's procurement data and MarketScape research,
recommend the top three vendors and deliver them as an Excel scorecard my evaluation team can use.
Cite sources.
```

## Your numbers versus IDC's forecast
```
[Upload: next year's IT budget]
Compare this budget to IDC's forecast for [segment / region]. Show where the two differ and by how much.
Cite the forecast dataset.
```

## Acquisition impact
```
[Competitor] just acquired [target]. Using IDC Quanta, analyze what this means for our business in
[market]. Produce an executive-ready brief and cite IDC research for each point.
```

## Market sizing / benchmark
```
Size the [market] for [region / period] and benchmark [our metric] against IDC data.
Use IDC's definitions and cite the dataset.
```

## Review checklist
- [ ] Every figure has an IDC citation.
- [ ] Definitions (market share, growth rate) match IDC's.
- [ ] Uploaded internal data was used only for the comparison.
- [ ] A person reviewed the output before it reached a decision maker.
