# Cost controls for the unified experience

Pricing remains usage-based. Agentic (cloud) work can use more tokens than quick chats, so set these
before broad enablement.

| Control | What it does | Decision to make |
|---|---|---|
| Efficient mode | Keeps the experience on Sonnet and Haiku models | Which groups default to efficient mode? |
| Model entitlements | Sets which models each role can use | Which roles get Opus-class models? |
| Spend limits | Caps spend at organization, group, and member levels | Values per level |
| Pooled group budgets | Gives a group one shared monthly amount | Which teams share a budget, and how much? |

## Model efficiency figures from the post
- Claude Opus 5.5: 40% less than Opus 5 on typical workloads.
- Claude Sonnet 5.5: up to 30% less than Sonnet 5 for most work.
