# Task examples by app and surface

Examples paraphrased from the announcement. Adapt the wording to your own files.

## Docs (add-on sidebar)
- "Fix this sentence." / "Restyle this heading." → applied in place.
- "Tighten the summary of this product requirements doc and turn the next steps into a table." →
  larger change, returned as suggestion cards to apply or dismiss.

## Sheets (add-on sidebar)
- "Write a formula for …", "Build a pivot table of …", "Add a chart of …", "Add a tab for …".
- "Clean this range and join it with the data on tab X." → Claude runs Python on the range and writes
  the results back.
- "Create a quarterly budget-vs-actuals workbook with a tab per team and a summary chart, and flag
  overspending."

## Slides (add-on sidebar)
- "Add slides for … using this deck's layouts and theme."
- "Check the deck for overlapping or off-slide elements and hard-to-read text."

## From a Claude chat (connectors)
- Paste a Google file link and ask for edits, or ask for a new doc, sheet, or deck.
- "Draft a quarterly business review deck for this customer using account history from Salesforce
  and call notes from Google Drive." Then save the format as a skill so teammates can reuse it.
