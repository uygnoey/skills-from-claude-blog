# 컨텍스트 엔지니어링의 새 규칙

Anthropic은 Claude 5 모델을 위해 **Claude Code 시스템 프롬프트의 80% 이상을 제거**했다. 코딩 평가에서
측정 가능한 성능 저하는 없었다. 여기서 얻을 수 있는 일반적인 교훈은 이렇다. 이전 세대 모델을 잘 작동하게
만들던 컨텍스트 엔지니어링은 새 세대 모델을 잘 작동하게 만드는 것이 아니며, 상당 부분은 이제 오히려
방해가 된다.

## Claude의 족쇄 풀기

기존 방식은 Claude를 과도하게 제약했다. 규칙은 시스템 프롬프트, CLAUDE.md 파일, 스킬이라는 세 계층에
걸쳐 쌓였고, 일정 수준을 넘자 서로 충돌하기 시작했다. 한쪽 계층은 문서를 적절히 남기라고 하고, 다른
계층은 주석을 달지 말라고 한다. 둘 다 따를 수는 없다.

새 모델은 그런 발판 없이도 사용자가 실제로 원하는 바를 해석할 수 있다. 그래서 남는 것은 발판의 해로운
부분뿐이다. 아무 이득 없이 행동 범위만 좁히는 모순된 지시다. 이것들을 제거하는 것은 지침을 잃는 일이
아니라 족쇄를 푸는 일이다.

두 번째로 달라진 것은 컨텍스트가 놓일 수 있는 자리다. 예전에는 Claude가 CLAUDE.md 하나에 메모리, 정보,
지침을 모두 의존했다. 이제 메모리, 아티팩트, 스킬이 있고, Claude는 이들을 통해 세션을 넘나들며 컨텍스트를
불러오고 공유하는 자체 방식을 만들어낼 수 있다. CLAUDE.md가 더 이상 모든 것을 짊어지지 않아도 되는
이유다.

## 여섯 가지 전환

**1. 규칙을 주기 → 판단에 맡기기.** 예전 문구는 이랬다. 기본적으로 주석을 쓰지 말 것, 여러 문단짜리
독스트링이나 여러 줄 주석 블록은 절대 쓰지 말 것, 최대 한 줄. 새 문구는 이렇다. 주변 코드처럼 읽히는
코드를 쓸 것 — 주석 밀도, 이름 짓기, 관용구를 주변에 맞출 것. 금지 조항은 원래 어떤 기준을 대신하고
있었을 뿐이다. 그 기준을 직접 말하면 된다.

**2. 예시를 주기 → 인터페이스를 설계하기.** 사용 예시는 새 모델에게 단지 설명이 아니라 **제약**으로
작동한다. 예시가 다루는 탐색 공간 안에 모델을 묶어둔다. 가르침을 도구 자체로 옮겨라. 표현력 있는 파라미터,
시그니처만 봐도 올바른 사용법이 드러날 만큼 명확하게 열거된 옵션이 그 역할을 한다.

**3. 전부 앞에 몰아넣기 → 점진적 공개.** 필요할지도 모르는 모든 것을 시스템 프롬프트에 싣는 대신, 스킬과
지연 로딩 도구를 통해 컨텍스트를 선택적으로 불러온다. 그러면 알맞은 지침이 알맞은 순간에 도착한다.

**4. 반복하기 → 간결한 도구 설명.** 예전에는 같은 지시가 시스템 프롬프트에도, 도구 설명에도 들어갔다.
이제는 도구 설명에만 둔다. 이전 모델은 반복에서 이득을 봤지만, 지금 모델은 도구 설명을 안정적으로
참조한다. 중복은 동기화해야 할 대상이 하나 늘어나는 일일 뿐이다.

**5. CLAUDE.md 안의 메모리 → 자동 메모리.** `#` 단축키로 컨텍스트를 직접 고정하는 방식은 더 이상 필요
없다. Claude가 작업과 사용자에게 관련 있는 메모리를 자동으로 보존한다.

**6. 단순한 명세 → 풍부한 레퍼런스.** 마크다운 계획서는 충실도가 낮은 선택지다. HTML 아티팩트, 코드
레퍼런스, 테스트 스위트, 루브릭은 같은 의도를 훨씬 적은 모호함으로 전달하고, Claude는 점점 더 복잡한
레퍼런스를 다룰 수 있다.

## 이제 각 계층이 맡는 일

**시스템 프롬프트.** 제품 컨텍스트다. 이 에이전트가 어떤 제품 안에서 어떤 역할로 동작하는지를 정한다.
Claude Code 사용자가 직접 손대는 일은 드물지만, 커스텀 에이전트를 만든다면 상당한 공을 들일 만한
계층이다.

**CLAUDE.md.** 가볍게 유지한다. 리포지토리에 대한 설명, 그리고 누가 알려주지 않으면 발견할 수 없는
함정에 집중한다. 지시가 복잡해지면 파일을 키우지 말고 별도 스킬로 옮겨 점진적 공개에 맡긴다.

**스킬.** 필요할 때 정보를 찾게 해주는 가벼운 안내서다. 결정적으로 중요한 영역이 아니라면 과도하게
제약하지 말고, 팀이나 제품에 고유한 관점과 모범 사례를 담아라. 긴 스킬은 여러 파일로 나눈다.

**레퍼런스.** 깊이가 들어가는 자리다. @멘션으로 명세, 목업, 코드베이스를 끌어온다. 서술형 텍스트보다
코드가 명확하고 충실하므로 코드를 우선한다.

## 어디서 시작할까

Claude Code에서 `/doctor`(CLI에서는 `claude doctor`)를 실행한다. 스킬, CLAUDE.md 파일, 시스템 프롬프트를
Claude 5 모델에 맞게 자동으로 적정 크기로 줄여준다. 기계적인 부분은 여기서 끝난다. 직접 손볼 몫은 그
다음이다. 계층 간 모순, 그리고 이제는 존재하지 않는 한계를 우회하려고 썼던 규칙들이다.

그다음에는 측정한다. 80%라는 숫자에는 평가가 함께 붙어 있었다. "측정 가능한 손실 없음"은 그냥 가정할
것이 아니라 자신의 에이전트에 대해서도 말할 수 있어야 하는 주장이다.

원문의 표현을 빌리면, 우리가 그랬듯 여러분도 단순화해야 할지 모른다.
