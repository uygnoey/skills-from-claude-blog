# The four credentials

Putting Claude to use at a large enterprise involves different roles and specialties. The Claude
Certification Program maps to the four largest ones. Three of the four were added in the July 2026
expansion; **Architect: Foundations** existed before it.

## Claude Certified Associate: Foundations *(new)*

Validates practical, everyday use of Claude for anyone working on Claude-related projects. It
applies to a wide range of roles including consultants, project leads, and both business and
technical expertise.

This is the credential for people whose contribution is using Claude well on a project, rather than
building or architecting with it.

## Claude Certified Developer: Foundations *(new)*

For engineers building applications with Claude. Includes training on:

- the Claude API
- tool use
- agent development

## Claude Certified Architect: Foundations

For solution architects who design and build agent systems with Claude.

## Claude Certified Architect: Professional *(new)*

The advanced credential, built for the scale of large enterprises. Covers:

- integration architecture
- governance
- evaluation

## Progression

Every path to getting credentialed starts with a foundation-level certification and advances to the
professional level. Offerings span non-technical roles through those that build and architect
Claude-based solutions.

Each certification was designed by subject matter experts so the content reflects the real work that
newly certified professionals will do. Completed certifications are recognized with partner badges,
which show demonstrated expertise in a specific product area.
