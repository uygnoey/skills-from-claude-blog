# Team 플랜과 모바일 접근

원문에서 발표된 두 가지 제품 변화와 각각의 쓰임새를 짧게 정리한 서베이입니다.

## 무엇이 발표되었나

**Claude Team 플랜** — 개인이 아니라 팀을 대상으로 한 유료 워크스페이스 플랜.

**Claude iOS 앱** — 모든 플랜에서 사용 가능한 무료 모바일 앱.

## Team 플랜

| 항목 | 원문에 명시된 내용 |
|---|---|
| 사용량 | 개인 플랜 대비 증가된 사용량 |
| 모델 | Claude 3 모델 제품군 — Opus, Sonnet, Haiku 접근 |
| 컨텍스트 윈도 | 200K |
| 관리 | 워크스페이스 관리를 위한 관리자 도구 |
| 기능 기준선 | Claude Pro에 포함된 모든 기능 |
| 가격 | 사용자당 월 $30 |
| 최소 인원 | 5석 |

### 잘 맞는 경우

- 팀에 개인 플랜이 제공하는 것보다 많은 1인당 사용량이 필요할 때.
- 구성원과 결제를 개인별이 아니라 중앙에서 관리해야 할 때.
- 작업 성격에 따라 Claude 3 제품군 안에서 모델을 골라 쓰는 것이 유리할 때. 어려운 추론에는 큰 모델을, 대량 처리에는 작은 모델을.
- 긴 컨텍스트 작업이 일상적이어서 200K 윈도가 의미 있을 때.

### 맞지 않는 경우

- 혼자 일하는 한 사람. 5석 최소 조건 때문에 1인당 경제성이 개인 플랜보다 나빠집니다.
- 가끔만 쓰고 사용량 제약이 없는 팀.

## iOS 앱

| 항목 | 원문에 명시된 내용 |
|---|---|
| 가격 | 모든 플랜에서 무료 |
| 대화 동기화 | 기기 간 대화 동기화 |
| 비전 | 사진과 파일 지원 |

### 실제로 무엇이 달라지나

계획에 넣을 만한 두 가지는 동기화와 비전입니다.

**동기화**는 모바일을 별개 표면이 아니라 이어지는 표면으로 만듭니다. 책상에서 시작한 대화를 이동 중에 이어받고 다시 책상에서 마무리할 수 있습니다. 긴 작성보다는 검토와 후속 처리에 유용합니다.

**휴대폰에서의 비전**은 카메라를 입력 경로로 만듭니다. 문서, 화이트보드, 화면, 실물을 촬영하는 편이 파일을 먼저 컴퓨터로 옮기는 것보다 빠른 경우가 많습니다.

## 실무 참고

- 구매를 결정하기 전에 현재 가격, 최소 좌석 수, 모델 제공 범위, 기능 구성을 확인하세요. 위 수치는 발표 시점 기준이며 제품 세부 사항은 변합니다.
- 원문에 명시되지 않은 것 — 지역별 제공 여부, 조달 조건, 데이터 처리 세부 사항 — 은 이 요약에서 추론하지 말고 최신 공식 문서에서 확인하세요.
