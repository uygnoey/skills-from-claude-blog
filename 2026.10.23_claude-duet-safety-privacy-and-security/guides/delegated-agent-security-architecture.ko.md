# 위임형 에이전트의 보안 아키텍처 (Claude Duet)

Anthropic이 Claude Duet 리서치 프리뷰를 어떻게 보호했는지 정리합니다. Claude Duet은 클라우드 컴퓨터에서
계속 실행되며 사용자가 연결한 앱을 쓰는 에이전트입니다(2026년 10월 23일).

## 세 가지 원칙
1. 정보를 신중하게 다룬다.
2. 사용자가 통제권을 유지한다.
3. 자격증명을 에이전트에게서 떼어 놓는다.

보호 장치는 모델의 안전 학습, Claude Code와 Claude Managed Agents의 안전장치, 그리고 사용자를 대신해
행동하기 위한 새 통제 위에 쌓입니다.

## 1. 중요한 행동은 승인 받기
- 민감한 행동(메시지 전송, 결제, 삭제)은 행동·대상·내용을 보여 주고 승인을 기다립니다.
- Claude Code auto mode 분류기를 확장한 별도 자동 의도 검사가 모델 바깥에서 실행되므로, 페이지에 숨은
  지시가 영향을 줄 수 없습니다.
- 일부 행동은 승인이 있어도 금지됩니다: 증권 거래, 계좌 간 자금 이동, 다른 사람 계정 접근.
- 승인 피로를 피하도록 승인 빈도를 조정 중입니다.
- 구매는 한 가맹점·한 금액으로 제한된 일회용 카드(Stripe의 Link)를 씁니다.

## 2. 정보는 신중하게
- 별도 분류기가 나가는 메시지마다 검사합니다.
- 절대 공유 금지: 로그인 자격증명, 전체 카드·계좌 번호, 정부 발급 신분증 번호.
- 동의 필요: 건강·금융 정보 같은 그 밖의 개인 정보. 사용자의 요청 자체가 동의로 간주됩니다.
- 차단된 메시지는 민감한 내용을 뺀 버전으로 다시 써서 승인을 받을 수 있습니다.

## 3. 가시성
- 작업 목록으로 한 일과 진행 중인 일을 보여 주며, 작업 도중 방향을 바꿀 수 있습니다.
- 대화 기록과 메모리는 삭제·초기화 전까지 유지되고, 계정을 삭제하면 저장 데이터가 지워집니다.
- 앱 연결을 끊으면 새 접근은 멈추지만, 이미 학습한 정보는 메모리를 초기화할 때까지 남습니다.

## 4. 자격증명과 브라우저 격리
- 비밀번호: 앱 안의 폼에 입력하고, 일회용 키로 암호화되며, 브라우저 머신이 사이트에 입력합니다. 모델은
  보지 못합니다. 1Password 연동이 예정되어 있습니다.
- 토큰: 에이전트는 플레이스홀더만 보고, 에이전트 머신 밖의 프록시가 실제 값을 넣습니다.
- 브라우저: 전용 클라우드 VM에서 고정된 명령으로만 조작합니다. 사이트 코드와 쿠키는 그곳에 남고,
  페이지 텍스트와 다운로드는 에이전트에게 돌아옵니다.
- 고유한 User-Agent와 공개된 IP 주소로 자신을 밝히며, 일부 사이트는 차단을 선택했습니다.

## 5. 테스트
- 일상형 작업을 정상·지시 주입·과잉 행동 유도의 세 변형으로 평가.
- 정보 유출·미승인 행동·악성 프롬프트에 대한 레드팀, 시스템 전체 위협 모델.
- 외부 침투 테스트 업체의 소스 코드 검토, 클라우드 브라우저와 로그인 폼에 대한 후속 검토 진행 중.
- HackerOne의 Anthropic 공개 버그 바운티 대상.

## 계속 바뀌는 부분
승인 빈도, 로그인 방식, 민감 정보 검사는 프리뷰 기간에 계속 바뀝니다. 사용자는 Claude Duet에게 직접
문제를 보고할 수 있습니다.
