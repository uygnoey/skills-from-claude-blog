## この記事について
顧客事例をまとめた発表記事です(2026年9月23日)。CodeRabbit は Claude Marketplace を通じて Vercel プランを
拡大し、Power Digital と ThoughtSpot は Snowflake の利用を拡大しました。いずれも既存の Anthropic
コミットメントの一部を充てています。

## どんなときに役立つか
- Anthropic コミットメントを持つチームが、Claude と併用しているデータ/インフラベンダーを拡大したいとき。
- 新たな予算申請が必要なツールのアップグレードを遅らせそうなとき。
- Claude 上で開発するベンダーが Claude Marketplace での販売を検討するとき。

## 主なポイント
- Claude Marketplace では Anthropic コミットメントの一部をパートナーツールに充てられ、新たな予算申請なしに
  1つの投資でより多くをカバーできる。
- Power Digital: 顧客データを Snowflake で運用(Snowflake Cortex AI で Claude を実行)。マーケットプレイス経由で
  Snowflake のコミットメントを拡大。Claude 利用者は約12人のエンジニアから800人以上に増加。
- ThoughtSpot: Snowflake の推論 API で顧客データ上の Claude を実行し、その購入を Anthropic コミットメントに
  充当。AI アナリスト Spotter は Claude のコネクタとして提供。
- CodeRabbit: エージェントは Vercel Sandbox の microVM でコードを実行し、Vercel Workflows が処理を調整。
  従量課金からコミット型 Vercel プランへの移行を Anthropic コミットメントで賄い、1週間以内に契約。
- Snowflake と Vercel は、Claude で開発する顧客により早く届く経路としてマーケットプレイスを位置づける。
- この形でのコミットメント利用は限定プレビュー。アカウントチームに相談するかリクエストを送信する。
