# Availability and limits (as announced, September 17, 2026)

## Rollout
- Beta starts for select Claude Pro and Max subscribers who use cloud sessions in Claude Code and have no
  existing projects on the web or desktop.
- Access expands to more Claude Code users on those plans over the following week.
- Updated projects for all Claude plans, plus Team and Enterprise, come after that.
- Pro and Max users without access can join a waitlist (claude.com/form/projects).
- Existing Pro and Max projects keep working as before and will be upgraded as the rollout reaches chat
  and Cowork.

## Limits and roadmap
- Several threads run at once, each a full Claude Code session, so usage limits may be reached faster.
- Project-specific usage is visible; model and effort are selectable for coordinator and worker threads.
- Threads run in the cloud today. Running on the local machine, alongside local tools and behind your
  network, was described as "coming very soon."
