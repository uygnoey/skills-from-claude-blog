## この記事について
Anthropic が Claude Enterprise 向けに、より充実した管理者アナリティクス、モデル単位のエンタイトルメント、支出アラートを導入した。前提はこうだ。Claude が組織全体でますます難しく複雑なエージェンティック業務を担うようになると、利用状況とコストのパターンは標準的なチャットツールのそれではなくなる。だから管理者には、Claude がどう使われているかを理解する可視性と、コストを動かすレバーの両方が必要になる。

可視性の側: グループ別・ユーザー別に分解され、IT がすでに管理する SCIM グループでフィルタでき、成果（作成されたアーティファクト、編集されたファイル、使用されたスキルとコネクタ）をそのコストの隣に並べて示すアナリティクスダッシュボード。利用と価値を分けた Claude Code の 2 つの新タブ（価値の算式はすべて可視で、入力値は調整可能）。平易な言葉の質問にエクスポート可能なチャートで答えるアナリティクスチャット。そして同じデータを Datadog Cloud Cost Management や CloudZero など財務・IT が既に使うツールへ取り込む Analytics API。

制御の側: 日常業務が最も高価なモデルで始まらないようにするモデルのデフォルトとエンタイトルメント、管理者 75%／90%・ユーザー 75%／95% の支出しきい値アラート、そして手作業では追えないほどグループが増えたときにコスト制御のワークフローをスクリプト化する Admin API。いずれも既存の制御 — あらゆる階層の支出上限、アクセスとモデルのルーティング、エクスポート付きの利用ダッシュボード、effort 制御 — の上に積み上がる。

## どんなときに役立つか
- 組織の利用・コストのパターンが、チャットではなくエージェンティック業務の形を取り始めたとき。
- 財務や IT が Claude の利用・コストを他のクラウド／AI 支出と並べて見る必要があるとき。
- 日常的な業務が、利用可能な中で最も高価なモデルを既定にしてしまっているとき。
- ユーザーが作業の途中で支出上限に達し、誰も予兆に気づいていなかったとき。
- チーム単位・シート単位でこの導入がどんな価値を返しているのかを問われ、その答えが検証に耐える必要があるとき。
- グループ別の上限が、管理者がクリックで確認できる範囲を超えたとき。

## 主なポイント
- **グループ別・ユーザー別の利用状況とコスト。** 作成されたアーティファクト、編集されたファイル、使用されたスキルとコネクタといった成果をコストの隣に表示し、既存の SCIM グループでフィルタできる。
- **Claude Code は利用と価値を分ける。** 利用: アクティブな開発者、セッション数、よく使われたコマンド（毎日更新）。価値: 生産性向上、コミットあたりコスト、年間価値 — 算式はすべて可視で、入力値は調整できる。
- **アナリティクスチャットは平易な言葉の質問を受け付ける**（「今月 Claude の利用が倍増したチームは？」「シートあたりの価値が最も高いのは？」）。返るのはエクスポートして共有できるチャートだ。
- **Analytics API は期間・チーム・製品・モデルでフィルタでき**、スキルは自身の利用とコストを報告し、新しいエンドポイントがプラグイン導入とアーティファクト作成を追跡する。名指しされた連携先は Datadog Cloud Cost Management と CloudZero。
- **ユーザーは自分の利用状況を見られる** — 時系列の傾向、最も依存している製品・モデル・スキル、それが支出としてどう積み上がるか。予期せぬ打ち切りを防ぐためだ。
- **モデルのデフォルトとエンタイトルメント**が、chat・Cowork・Claude Code をまたいで新しい会話の開始モデルと、各ロールがそもそも到達できるモデルを決める。
- **支出しきい値アラートは管理者に 75%・90%**、**ユーザーにアプリ内で 75%・95%** で発火し、ユーザーは Claude を離れずに管理者へ引き上げを申請できる。
- **Admin API は 3 つの名指しされたワークフローをスクリプト化する。** 引き上げ申請のレビュー、支出上限に近づいているメンバーの特定、急激な利用変化の検知。
- **記事に登場する 3 つのステークホルダー視点:** 月末の驚きではなく定期的な見直しのきっかけとしてのコスト可視性、ROI を主張するためにチーム単位でコストとビジネスインパクトを並べて読むこと（ある CIO はエンタープライズ MCP サーバーに接続された Claude を 4% の増収と結びつける）、そしてトークン数よりも組織全体で繰り返し実行されるスキルこそが本当の価値のシグナルだという見方。
