# Claude Enterprise 관리자 애널리틱스와 비용 제어

Anthropic이 Claude Enterprise를 위한 더 풍부한 관리자 애널리틱스, 모델 단위 권한(entitlement), 지출
알림을 도입했다. 이유는 분명하게 제시된다. **Claude가 조직 전반에서 점점 더 어렵고 복잡한 에이전틱 작업을
맡게 되면서, 사용량과 비용 패턴이 일반적인 채팅 도구와 달라졌기 때문이다.** 이번 제어 기능은 관리자에게
Claude가 어떻게 쓰이는지 파악할 가시성과 비용을 관리할 수단을 제공한다.

이번 추가 기능은 Anthropic이 이미 제공하던 제어 위에 얹힌다. 모든 계층의 지출 상한, 접근 및 모델
라우팅, 내보내기와 Analytics API를 갖춘 사용량 애널리틱스 대시보드, 그리고 effort 제어가 그것이다. 더
풍부한 애널리틱스와 더 세밀한 비용 제어는 수개월에 걸쳐 쌓아 온 제어 표면(control surface)에 가장 최근
더해진 부분이다.

## 도입 현황과 비용 추적

### 애널리틱스 대시보드

관리자용 애널리틱스 대시보드는 이제 **그룹별·사용자별 사용량과 비용**을 보여주며, 생성된 아티팩트, 편집된
파일, 사용된 스킬과 커넥터 같은 산출물을 해당 비용 바로 옆에 함께 표시한다. 관리자는 IT 팀이 이미 관리하는
**SCIM 그룹**으로 필터링할 수 있어, 분석 결과가 기존 조직도를 그대로 따른다.

### Claude Code 인사이트

Claude Code는 관리자 콘솔 안에 가치(value)와 사용량(usage)에 초점을 맞춘 두 개의 새 탭으로 더 풍부한
인사이트를 제공한다.

**사용량 탭**은 조직 전반의 활성 개발자 수, 세션 수, 가장 많이 쓰인 명령을 보여주며 매일 갱신된다.

**가치 탭**은 사용량과 비용 데이터를 요약해 Claude Code의 가치를 한눈에 파악하도록 돕고, 생산성 향상,
커밋당 비용, 연간 가치를 추정한다. 모든 산식이 탭에 그대로 노출되며 입력값은 조정할 수 있다.

### 애널리틱스 챗

애널리틱스 챗은 이제 훨씬 넓은 범위의 질문에 답하고, 더 깊이 파고들 수 있는 풍부한 아티팩트를 만들어낸다.
관리자는 "이번 달 Claude 사용량이 두 배가 된 팀은 어디인가?" "시트당 가치가 가장 높은 곳은 어디인가?"처럼
평이한 언어로 묻고, Claude는 내보내서 이해관계자와 공유할 수 있는 차트를 돌려준다.

### Analytics API

사용량과 비용 데이터는 Analytics API를 통해 프로그램적으로 이용할 수 있어, 재무와 IT가 이미 쓰는
도구 — **Datadog Cloud Cost Management**, **CloudZero** 등 — 로 데이터를 가져와 나머지 클라우드·AI 지출과
나란히 볼 수 있다. 결과는 **기간, 팀, 제품, 모델**로 필터링할 수 있다. **스킬은 자체 사용량과 비용을
보고하며**, 새 엔드포인트가 **플러그인 도입률**과 **아티팩트 생성**을 추적한다.

### 사용자 단위 가시성

관리자는 사용량 가시성을 개별 사용자에게까지 확장할 수 있다. 비용, 제품·모델별 분해, 지출 한도 대비 진행
상황을 볼 수 있어 누구도 예고 없이 차단당하지 않는다. 사용자 역시 자신의 사용량 추세를 시간에 따라 확인할
수 있으며, 어떤 제품·모델·스킬에 가장 많이 의존하는지, 그 활동이 지출로 얼마나 쌓이는지를 볼 수 있다.

## 지출 관리를 위한 제어

**모델 기본값과 권한**을 통해 관리자는 chat, Cowork, Claude Code 전반에서 새 대화가 어떤 Claude 모델로
시작할지 정할 수 있다. 일상적인 작업이 반드시 가장 비싼 선택지로 기본 설정되지 않게 하기 위해서다.
관리자는 어떤 모델을 특정 역할에 열어 줄지, 조직 전체에 열어 줄지도 제어한다.

**지출 임계값 알림**은 조직 단위 지출 한도의 **75%**와 **90%** 시점에 관리자에게 알려, 누군가 작업 도중
막히기 전에 한도를 올릴 시간을 준다. 사용자는 **75%**와 **95%**에 인앱 알림을 받고, Claude를 벗어나지 않고
관리자에게 직접 한도 상향을 요청할 수 있다.

**Admin API**는 여러 그룹에 걸쳐 한도를 관리하는 조직을 위해 비용 제어 워크플로를 스크립트로 옮겨, 제어가
조직 규모에 맞춰 확장되게 한다. 상향 요청 검토 자동화, 지출 한도에 근접한 구성원 식별, 급격한 사용량 변화
표시를 모두 대규모로 처리할 수 있다.

## 시작하기

조직 전반에서 Claude를 관리하는 관리자를 위한 출발점은 이렇다. 관리자 콘솔에서 사용량과 비용 분해를
살펴보고, 그룹별로 모델 기본값과 지출 한도를 설정하고, 초과 지출에 앞서 대응하도록 지출 임계값 알림을
구성한다. 사용량 데이터는 관리자 대시보드에서 볼 수 있으며, Analytics API를 통해 재무와 IT가 동일한 지표를
기존 리포팅 시스템으로 가져올 수 있다.
