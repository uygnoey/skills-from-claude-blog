# Claude Enterprise の管理者アナリティクスとコスト制御

Anthropic は Claude Enterprise 向けに、より充実した管理者アナリティクス、モデル単位のエンタイトルメント、
支出アラートを導入した。その理由は明確に述べられている。**Claude が組織全体でますます難しく複雑なエージェ
ンティック業務を担うようになるにつれ、利用状況とコストのパターンは標準的なチャットツールとは異なるものに
なる。** これらの制御は、Claude がどう使われているかを把握するための可視性と、コストを管理するための手段を
管理者に与える。

今回の追加は、Anthropic がすでに提供していた制御の上に積み上がるものだ。すなわち、あらゆる階層での支出上
限、アクセスとモデルのルーティング、エクスポートと Analytics API を備えた利用状況アナリティクスダッシュ
ボード、そして effort 制御である。より充実したアナリティクスとより粒度の細かいコスト制御は、数か月かけて
築いてきた制御面（control surface）への最新の追加にあたる。

## 導入状況とコストの把握

### アナリティクスダッシュボード

管理者向けアナリティクスダッシュボードは、**グループ別・ユーザー別の利用状況とコスト**を表示するようにな
り、作成されたアーティファクト、編集されたファイル、使用されたスキルやコネクタといった成果を、そのコスト
のすぐ隣に並べて示す。管理者は IT チームがすでに管理している **SCIM グループ**でフィルタできるため、内訳は
既存の組織図にそのまま沿う。

### Claude Code のインサイト

Claude Code は、管理コンソール内の価値（value）と利用（usage）に焦点を当てた 2 つの新しいタブによって、よ
り充実したインサイトを得られるようになった。

**利用タブ**は、組織全体のアクティブな開発者数、セッション数、よく使われたコマンドを示し、毎日更新される。

**価値タブ**は利用状況とコストのデータを要約し、Claude Code の価値を一目で把握できるようにする。生産性の向
上、コミットあたりのコスト、年間価値を推定する。すべての算式はタブ上に可視化されており、入力値は調整でき
る。

### アナリティクスチャット

アナリティクスチャットは、はるかに幅広い質問に答え、掘り下げられる充実したアーティファクトを生成できるよう
になった。管理者は「今月 Claude の利用が倍増したチームはどこか」「シートあたりの価値が最も高いのはどこか」
といった平易な言葉で尋ね、Claude はエクスポートしてステークホルダーと共有できるチャートを返す。

### Analytics API

利用状況とコストのデータは Analytics API を通じてプログラムから利用でき、財務や IT がすでに運用している
ツール — **Datadog Cloud Cost Management** や **CloudZero** など — に取り込んで、他のクラウド／AI 支出と並
べて見ることができる。結果は**期間、チーム、製品、モデル**でフィルタできる。**スキルは自身の利用状況とコス
トを報告し**、新しいエンドポイントが**プラグインの導入状況**と**アーティファクト作成**を追跡する。

### ユーザー単位の可視性

管理者は利用状況の可視性を個々のユーザーにまで広げられる。コスト、製品・モデル別の内訳、支出上限に対する進
捗が見えるため、誰も予期せぬ打ち切りに遭わない。ユーザー自身も、時系列での利用傾向、最も依存している製品・
モデル・スキル、そしてその活動がどれだけの支出になっているかを確認できる。

## 支出を管理するための制御

**モデルのデフォルトとエンタイトルメント**により、管理者は chat、Cowork、Claude Code をまたいで、新しい会話
がどの Claude モデルで開始されるかを設定できる。日常的な業務が必ずしも最も高価な選択肢を既定にしないように
するためだ。管理者は、どのモデルを特定のロールに、あるいは組織全体に開放するかも制御する。

**支出しきい値アラート**は、組織単位の支出上限の **75%** と **90%** の時点で管理者に通知し、誰かが作業の途中
でブロックされる前に上限を引き上げる時間を与える。ユーザーには **75%** と **95%** でアプリ内通知が届き、
Claude を離れることなく管理者に上限引き上げを直接申請できる。

**Admin API** は、多数のグループにまたがって上限を管理する組織向けに、コスト制御のワークフローをスクリプト
へ移し、制御が組織規模に合わせて拡張できるようにする。引き上げ申請のレビュー自動化、支出上限に近づいている
メンバーの特定、急激な利用変化の検知を、いずれも大規模に実行できる。

## 使う側が求めていること

> 「コストの可視性は月に一度の作業ではありません。粒度の細かい支出データとアラートは、請求サイクルの終わり
> に驚かされる代わりに、チームが Claude の使い方を定期的に見直すきっかけを与えてくれます。」
>
> — Kyra Abbu（プロダクトマネージャー）

> 「最高の四半期を牽引している人たちの速度を落とすつもりはありません。彼は ROI を求めています。私たちは、
> エンタープライズの MCP サーバーに接続された Claude を 4% の増収と結びつけました。」
>
> — Carter Busse（CIO）

> 「トークン利用量だけでは大したことは分かりません。私が本当に見たいのは、組織全体で繰り返し実行されている
> スキルは何かということです。それこそが本当の価値のシグナルです。」
>
> — Ciro Yamada（プロダクトディレクター）

## はじめ方

組織全体で Claude を管理する管理者向けの出発点はこうだ。管理コンソールで利用状況とコストの内訳を確認し、グ
ループ単位でモデルのデフォルトと支出上限を設定し、超過に先回りできるよう支出しきい値アラートを構成する。利
用データは管理ダッシュボードで確認でき、Analytics API により財務と IT は同じ指標を既存のレポーティングシス
テムに取り込める。
