## この記事について
2026年9月23日に始まった Claude Marketplace の発表です。プラグインとコネクタ、Claude を使ったエージェントと
製品、サービスパートナーを一か所にまとめ、Claude を拡張したい顧客と、Claude を使うチームに届けたい企業の
両方の窓口になります。

## どんなときに役立つか
- チームが Claude 向けのコネクタ、プラグイン、パートナー製ソフトウェア、コンサルタントを探すとき。
- 購買部門が Anthropic へのコミット済み支出をパートナーのエージェントや製品に充てたいとき。
- ベンダーやコンサルティング会社が掲載を希望するとき。

## 主なポイント
- 顧客向け: 2,000 以上のコネクタとプラグイン（Atlassian、Google、Microsoft、Notion、Salesforce など）。
- Anthropic へのコミット済み支出の一部で、Claude を使ったソフトウェア（CrowdStrike、Cursor、Harvey、
  Legora、Lovable、Snowflake など）を購入できる。
- 戦略策定や全社展開のため、Claude Partner Network のコンサルティング会社・SI（Accenture、BCG、
  Deloitte など）とつながれる。
- ビルダー向け: コネクタ/プラグインは MCP と Agent Skills で構築し、エージェント/製品は掲載を申請し、
  コンサルティング会社・SI は Claude Partner Network に参加する。
- Notion、Salesforce、Snowflake、Atlassian、CrowdStrike、Hebbia、Legora のコメント。CodeRabbit は
  コミットを Vercel に、Power Digital と ThoughtSpot は Snowflake に充てた。
