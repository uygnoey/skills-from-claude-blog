## この記事について
**Claude in Chrome のサイドパネルが Claude Cowork セッションになった**という発表です。これまでサイドパネルの会話は Claude アプリの会話とは別物で、コンテキストが引き継がれませんでした。今後は会話が履歴に保存され、スキルとコネクターがブラウザでも動作し、タブで始めたタスクを Claude のデスクトップ・ウェブ・モバイルアプリで仕上げられます。セッションが単一のデバイスではなくアカウントに紐づくためです。本日から Max と Team プランで利用でき、Pro ユーザーには今後数週間かけて順次展開されます。

記事はブラウザというサーフェスの意義を示します。多くのツールは Claude に直接つながりますが、社内ダッシュボード、レガシーシステム、ベンダーポータルなど、そうでないものもあります。Claude in Chrome は既存のログインを使い、リンクのクリック、テキスト入力、ページ遷移、フォーム入力を行いながら、そうしたアプリの中で作業できます。そのうえでリスクを正面から扱います。Claude in Chrome は、ブラウザ上で行動するあらゆる AI エージェントと同じくプロンプトインジェクションにさらされます。ウェブページ、メール、ドキュメントに隠された指示はユーザーには見えない場合があり、意図しない行動へ Claude を誘導しかねません。パイロット以降、Claude 自身の行動に対するチェックが追加されました。「automatically approve」を有効にすると Claude は一手ごとに止まらず作業を進めますが、フォームの送信、メッセージの送信、ファイルのダウンロードといった重大な行動の前には、別のチェックがその行動を当初の依頼内容と照合し、一致しないものをブロックします。購入や個人データの共有など、取り消せない、あるいはコストのかかる特定の行動については、Claude は依然として確認します。記事は、これらの対策がリスクを有意に減らすものの、なくすことはできないと明言しています。

## どんなときに役立つか
- 作業対象が Claude のコネクターを持たないツール（社内ダッシュボード、レガシーシステム、ベンダーポータル）にあるとき。
- ブラウザで始めたタスクをローカルファイルのある場所で仕上げる必要があるとき、またはその逆のとき。
- ブラウザエージェントにどれだけ自律性を与えるかを判断するにあたり、スローガンではなく実際のガードレールの仕組みを知りたいとき。
- 管理者が Enterprise 組織で Claude in Chrome を有効化し、承認ドメインの範囲を決めるとき。

## 主なポイント
- **サイドパネルは Cowork セッション。** 会話は履歴に保存され、スキルとコネクターがブラウザで動作します。
- **セッションはデバイスではなくアカウントに従う。** タブで始めてデスクトップ・ウェブ・モバイルアプリで続けられ、コンテキストがサーフェスをまたいで引き継がれます。
- **ページ上でできること:** 表示中のページを見て、既存のログインを使いリンクのクリック、テキスト入力、ページ遷移、フォーム入力を行います。
- **ブラウザが重要な理由:** Claude に直接つながらない社内ダッシュボード、レガシーシステム、ベンダーポータルに届きます。
- **記事の例:** 複数のベンダーポータルから請求書の金額と日付を集めて予算スプレッドシートを作らせ、そのセッションをデスクトップアプリで引き継いでローカルファイルを追加したり、先月の予算を取り込んで何が変わったかを尋ねたりする。
- **主なリスクはプロンプトインジェクション。** ウェブコンテンツ（ページ、メール、ドキュメント）に隠された悪意ある指示はユーザーに見えないことがあり、依頼していない行動へ Claude を向けさせます。
- **行動チェック。**「automatically approve」有効時、フォーム送信・メッセージ送信・ファイルダウンロードといった重大な行動は、別のチェックが当初の依頼と照合し、一致しないものをブロックします。中断は減り、監督は保たれます。
- **確認は残る。** 購入や個人データの共有など、取り消せない、あるいはコストのかかる特定の行動については Claude が先に確認します。
- **明示された限界。** これらの対策はリスクを有意に減らしますが、なくすことはできません。プロンプトインジェクションは動き続ける標的であり、信頼できるサイトから始めることが推奨されています。
- **提供状況。** 本日 Max と Team、Pro は今後数週間で順次。Enterprise では Claude in Chrome は**既定でオフ**で、管理者が有効化し、承認ドメインに限定できます。
- **対象外。** 自分のコンピューター上のファイルや他のアプリケーションを扱うには依然としてデスクトップアプリが必要で、Claude in Chrome は他の Chromium ブラウザやモバイルではまだ動作しません。
