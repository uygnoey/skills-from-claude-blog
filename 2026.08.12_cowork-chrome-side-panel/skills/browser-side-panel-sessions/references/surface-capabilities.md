# Surfaces, capabilities, and availability

From the announcement. Anything not listed is not established by the source.

## What changed

The Claude in Chrome side panel **is now a Claude Cowork session**.

- Conversations are saved to your history.
- Your skills and connectors work in the browser.
- A task started in a tab can be finished in the Claude desktop, web, and mobile apps.
- Sessions live **with your account rather than a single device**, so work started in a
  browser can be picked up later somewhere else.

Before this change, a side-panel session was separate from those in the Claude apps, so
context and conversations did not carry between them.

## What Claude can do in a page

Claude in Chrome is a browser extension that lets Claude see the page you're on and take
actions in it:

- clicking links
- typing text
- navigating between pages
- filling out forms

It does this **using your existing logins**.

## Why the browser surface exists

Many tools you use every day connect directly to Claude. Others don't:

- internal dashboards
- legacy systems
- vendor portals

With Claude in Chrome, Claude can work in these apps through the browser.

## Surface selection

| Need | Surface |
| --- | --- |
| A tool behind a login with no direct connector | Chrome side panel |
| Reading and acting inside a web page | Chrome side panel |
| Files on your computer | Desktop app |
| Other applications on your machine | Desktop app |
| Continuing a browser-started task elsewhere | Desktop, web, or mobile app |

## Availability

| Plan | Status |
| --- | --- |
| Max | Available today |
| Team | Available today |
| Pro | Rolling out over the coming weeks |
| Enterprise | Claude in Chrome is **off by default**; admins turn it on and can limit it to approved domains |

## Not supported yet

- Other Chromium browsers (non-Chrome)
- Mobile

## Getting started

1. Install Claude in Chrome from the Chrome Web Store.
2. Sign in.
3. Open the side panel.
