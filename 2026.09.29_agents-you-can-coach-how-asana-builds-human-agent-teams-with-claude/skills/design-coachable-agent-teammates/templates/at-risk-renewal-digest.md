# At-risk renewals — daily digest (<date>)

Structure of the digest Asana's At-Risk Renewal agent produces: it reads every at-risk renewal task
(CSM updates, status notes, comments), builds a global view first, then cuts by region. It is pushed
each morning to the Chief Customer Officer, Chief Revenue Officer, and regional customer success
leaders in a shared space.
