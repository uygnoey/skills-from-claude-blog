## この記事について
Claude Code の動作と見た目を変える小さな TypeScript 関数「mod」を紹介する記事です。mod はプロンプトの
書き換え、新しい UI の追加、組み込み機能の置き換え、まったく新しい機能の追加ができます。mod は plugin
に含めて配布され、Claude Code CLI とデスクトップアプリで動作します。

## どんなときに役立つか
- 新機能のリリースを待たずに、Claude Code を自分のやり方に合わせたいとき。
- hook では足りないとき — イベントの書き換え、UI の描画、機能の置き換えが必要なとき。
- チームが CI ステータス、本番環境の保護、監査ログなど独自の統制を作りたいとき。
- 管理者がユーザーのインストールできる mod を管理する必要があるとき。

## 主なポイント
- Claude Code は何かをするたびにイベントを発行します（ツール呼び出し、権限リクエスト、画面の一部の
  描画など）。mod はイベントにフックし、その前・後・代わりに、または前後を包んで実行されます。
- 関数ひとつでプロンプトの書き換え、ツール呼び出しのブロック・書き換え・再試行、権限の承認・拒否、
  ツール出力からの秘密情報の除去ができます。UI の編集・置き換えやボタン・入力欄の追加も可能で、対象は
  ターミナル、デスクトップアプリ、またはその両方です。
- 同じイベントの mod はロード順に実行されます。最初にロードされた mod がイベントを最初に、結果を最後に
  見るため、異なる作者の mod を積み重ねられます。
- 組み込み機能は mod へ移行中です — `/diff` はすでに mod で、`/plugin` で無効化したり置き換えたり
  できます。
- mod はサンドボックス化されていないので、信頼できる提供元からのみインストールします。既存の plugin
  管理がそのまま適用され、Team/Enterprise や managed settings のある端末では組み込みの `sec-default`
  mod が最初にロードされ、権限の deny ルールの上書きなど危険な動作を防ぎます。
- Claude Code に頼めば、TypeScript の作成、インストール、セッション内のホットリロードまで行います。

## 同梱リソース
- Skill: `plan-code-mods` — mod の範囲（イベント、フェーズ、表示面、ロード順）の決め方、mod と hook の
  選び方、チームでの統制方法と mod 設計ワークシート。
