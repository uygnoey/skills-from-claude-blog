## 이 글이 뭔가요
같은 작업을 하는 두 Claude Code 세션의 비용이 왜 크게 달라지는지, 그리고 우리가 통제할 수 있는 것이 무엇인지에 대한 Lydia Hallie의 실용 가이드. 에이전틱 코딩 도구는 좌석이 아니라 토큰 단위로 청구되므로, 질문은 토큰을 어떻게 덜 쓰느냐가 아니다. 쓰는 토큰이 실제로 요청한 작업을 향하도록 유지하는 것, 관련 없는 파일과 명령 출력을 매 턴 다시 보내지 않는 것이다.

문제를 두 변수로 쪼갠다. 토큰 하나의 값(모델, 입력 대 출력, 프롬프트 캐싱)과 세션이 보내는 토큰의 양(무엇이 컨텍스트에 들어오고 얼마나 오래 남는가). 마지막에는 어디부터 손봐야 하는지의 대략적인 우선순위를 준다.

## 언제 유용한가요
- 세션 비용이 비싸게 느껴지는데 어디로 새는지 분명하지 않을 때.
- 긴 대화가 그날 아침의 무관한 읽기까지 매 턴 끌고 다닐 때.
- `/clear`, `/compact`, `/rewind` 중 무엇을 쓸지 정할 때.
- 연결된 MCP 서버의 툴 정의나 비대해진 `CLAUDE.md`가 입력하기도 전에 컨텍스트를 채우고 있을 때.
- 로그 훑기나 트레이스 분석 같은 시끄러운 작업을 서브에이전트에 넘길지 판단할 때.
- 팀을 에이전틱 코딩에 온보딩하면서 습관을 초기에 잡아주고 싶을 때.

## 핵심 포인트
- **출력 토큰은 입력의 약 5배**이고 사고 토큰은 출력 토큰이다. 그래서 effort 레벨은 비싼 쪽을 직접 조절하는 다이얼이다. `MAX_THINKING_TOKENS=0`은 한 세션 동안 `/effort low`보다 한 단계 아래로 내려간다(Fable 5에는 해당 없음).
- **캐시 읽기는 입력가의 약 0.1배, 캐시 쓰기는 최대 2배이며 토큰당 한 번**이다. 캐시를 지키는 일이 다른 대부분의 최적화보다 중요하다.
- **캐시를 깨는 것:** `/model`, `/effort`, fast 모드는 모두 캐시 키의 일부라 전체 재프리필을 강제한다. `/compact`는 대화를 교체한다(시스템 프롬프트는 유지). 캐시는 구독에서 1시간, API 키에서 5분 후 만료되며 `ENABLE_PROMPT_CACHING_1H=1`로 후자를 연장할 수 있다.
- **`/rewind`는 무료다** — 끝을 잘라내고 캐시는 그대로 둔다. `/compact`는 항상 비용이 들기 때문에, 캐시가 만료된 뒤가 아니라 자리를 비우기 *전에* 컴팩트해야 한다.
- **새 세션에서 `/model`과 `/effort`를 한 번 확인하라.** 둘 다 이전 세션에서 이어지므로 지금 걸린 값이 의도한 값이 아닐 수 있다.
- **한 번만 보내지는 것은 없다.** 읽은 모든 파일과 명령 출력은 이후 매 턴 다시 전송된다. 캐시되어 싸지만 컨텍스트를 차지한다. 40번째 턴은 앞선 39개 턴의 값을 치르며, 그래서 하나의 긴 세션이 같은 작업을 쪼갠 것보다 비싸다.
- **`/context`를 한 번 실행하라.** 툴 정의, 시스템 프롬프트, `CLAUDE.md`, 시작 항목 등 상시 부하가 보인다. `CLAUDE.md`는 구체적으로 유지하고, 워크플로 지시는 필요할 때만 로드되는 스킬로 옮기고, 안 쓰는 MCP 서버는 `/mcp`로 끈다.
- **파일을 가리켜라.** 모호한 요청은 grep과 여러 번의 읽기를 부르고, 파일을 지정하면 Read 한 번, `@`로 멘션하면 아예 없다 — 메시지 전송 전에 첨부되기 때문이다. 대화당 한 번만 멘션하라. 다시 멘션하면 사본이 하나 더 붙는다.
- **명령을 조용하게 만들어라.** 출력은 파일 읽기처럼 덧붙고 세션 내내 남는다. 하루 종일 쓰는 명령 두세 개를 조용한 플래그와 함께 `CLAUDE.md`에 적어두라. 대략 3만 자를 넘는 출력은 파일로 쓰이고 미리보기만 남는다(`BASH_MAX_OUTPUT_LENGTH`).
- **`/loop`는 시작한 세션 안에서 전체 턴으로 발화**하며 매번 대화 전체를 끌고 간다. 발화 간격이 한 시간을 넘으면 캐시도 놓친다. 루프는 다른 터미널의 새 세션에서 돌려라.
- **서브에이전트는 자기 컨텍스트를 갖지만 당신의 대화는 갖지 않고**, 돌아오는 것은 답변뿐이다. 필요 없는 출력이 많이 나오는 작업에 값어치를 한다. 반복해서 넘기는 시끄러운 작업이라면 서브에이전트 설정에 더 작은 모델을 고정하라.
- **어디부터 볼 것인가**는 대략 영향 순으로 세션 길이, 명령 출력 크기, 읽은 파일, 모델과 effort다.
- 1M 컨텍스트 모델에서는 `/autocompact 200k`로 자동 컴팩트 안전망을 되살린다(Claude Code v2.1.221+).
